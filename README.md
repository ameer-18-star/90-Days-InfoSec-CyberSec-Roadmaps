# 🌐 Cybersecurity & InfoSec Career Roadmap

A sleek, interactive, and comprehensive dark-themed directory mapping out cybersecurity and information security job roles across three critical career tiers: **Entry-Level**, **Mid-Level**, and **Advanced-Level**.

Designed to serve as a career compass, each listed role links to a dedicated sub-page outlining technical responsibilities, key functions, expected skill sets, and recommended certifications.

## ✨ Features

* **Premium Cyberpunk Dark Theme:** Highly readable typography, custom glassmorphism containers, smooth fade-in entrance animations, and clean hover micro-interactions.
* **Logical Career Progression:** Roles are broken down into **Entry-Level (Tier 1 Support & Analysts)**, **Mid-Level (Specialists & Engineers)**, and **Advanced-Level (Leads & Architects)**.
* **Fully Responsive Layout:** Seamless experience across desktop monitors, tablets, and mobile phones.

## 🛠️ Quick Start & Deployment

Hosting this project on **GitHub Pages** takes less than a minute:

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME

```

### Step 2: Push to GitHub

Make sure your files are pushed to your main/master branch on GitHub.

### Step 3: Enable GitHub Pages

1. Go to your repository on GitHub.
2. Click on **Settings** (gear icon) in the top navigation bar.
3. Scroll down to the **Pages** section in the left sidebar (under "Code and automation").
4. Under **Build and deployment -> Source**, select **Deploy from a branch**.
5. Choose your branch (typically `main` or `master`) and folder (`/ (root)`).
6. Click **Save**.

*Your site will be live at `https://<your-github-username>.github.io/<your-repo-name>/` within a few moments!*
