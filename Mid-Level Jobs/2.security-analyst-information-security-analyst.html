90-Day Roadmap For "Security Analyst / Information Security Analyst"

Your accelerated path to becoming a proficient Security Analyst, equipped to identify, analyze, and respond to cyber threats.

Phase 1: Foundational Knowledge & Core Concepts

Days 1-30: Building a strong base in IT and security principles.

🎯 Phase 1 Goals

Networking Fundamentals Operating Systems Basics Security Principles Threat Landscape Overview Basic Linux Commands

Week 1: Networking & OS Fundamentals

  • Understand TCP/IP model, common protocols (HTTP, DNS, SMTP, etc.).
  • Learn about IP addressing, subnetting, and routing.
  • Explore basic Windows and Linux OS architecture and file systems.
  • Familiarize yourself with command-line interfaces (CMD, Bash).
  • Differentiate between common network devices (routers, switches, firewalls).
  • Introduction to Virtualization (VirtualBox/VMware).
  • Understand the CIA Triad (Confidentiality, Integrity, Availability).
  • Explore common network topologies.
TCP/IP OSI Model Windows OS Linux Basics

Task: Set up a virtual lab environment.

Install VirtualBox/VMware and set up two virtual machines: one Windows and one Linux (e.g., Ubuntu/Kali Linux). Configure basic networking between them.

Week 2: Security Concepts & Principles

  • Dive deeper into the CIA Triad and its practical application.
  • Learn about access control models (RBAC, DAC, MAC).
  • Understand authentication methods (passwords, MFA, biometrics).
  • Explore cryptography basics (symmetric, asymmetric encryption, hashing).
  • Introduction to common cyber threats (malware, phishing, DoS).
  • Understand the concept of vulnerabilities and exploits.
  • Familiarize yourself with security policies and procedures.
  • Learn about security baselines.
CIA Triad Access Control Cryptography Threat Types

Task: Research and summarize a recent cyberattack.

Choose a notable cyberattack from the past year. Identify the type of attack, the vulnerabilities exploited, and the impact. Present your findings.

Week 3: Network Security & Defense

  • Understand firewall concepts and rules.
  • Explore intrusion detection/prevention systems (IDS/IPS).
  • Learn about VPNs and secure remote access.
  • Familiarize yourself with network segmentation and VLANs.
  • Introduction to Wireshark for network traffic analysis.
  • Understand secure network protocols (HTTPS, SSH, SFTP).
  • Learn about port scanning and basic vulnerability scanning concepts.
  • Explore secure network configurations.
Firewalls IDS/IPS Wireshark VPNs

Task: Analyze network traffic with Wireshark.

Capture network traffic in your virtual lab and identify common protocols, source/destination IPs, and basic packet structures. Look for any unusual activity.

Week 4: Endpoint Security & Vulnerability Management

  • Understand antivirus/anti-malware solutions.
  • Learn about host-based firewalls and endpoint detection & response (EDR).
  • Explore patch management strategies.
  • Introduction to vulnerability scanning tools (e.g., Nessus, OpenVAS basics).
  • Understand the importance of security configurations and hardening.
  • Familiarize yourself with asset management in a security context.
  • Learn about basic security logging on endpoints.
  • Understand user account management and least privilege.
Antivirus Patch Management Vulnerability Scanners Endpoint Security

Task: Conduct a basic vulnerability scan on a virtual machine.

Using a tool like OpenVAS, perform a credentialed scan on one of your virtual machines. Analyze the report and identify critical vulnerabilities.

🎯 Milestone 1 Achievement

You've established a solid foundation in core IT and security concepts, understanding networking, operating systems, fundamental security principles, and basic defensive mechanisms. You're now ready to delve deeper into threat analysis and incident response.

Projects After Phase 1

Choose one of the following projects to solidify your foundational understanding:

Network Reconnaissance & Mapping

Map out a small virtual network, identifying active hosts, open ports, and services running on them using Nmap. Document your findings.

Hints: Use your virtual lab, Nmap commands like `nmap -sS -O -sV [target IP]`, research common port numbers.

Basic Malware Analysis Report

Research a common malware strain (e.g., a specific ransomware). Detail its infection vector, payload, and indicators of compromise (IOCs). Present it as a brief security alert.

Hints: Use public threat intelligence reports, malware analysis blogs (e.g., SANS Internet Storm Center). Focus on observable behaviors.

Operating System Hardening Checklist

Create a basic security hardening checklist for a Windows or Linux operating system, covering essential steps like disabling unnecessary services, strong password policies, and firewall configurations.

Hints: Refer to CIS Benchmarks for guidance, focus on practical and impactful steps for a new installation.

Investigate Network Connectivity Issues

Simulate a common network connectivity issue (e.g., wrong IP, firewall blocking) in your virtual lab and use `ping`, `traceroute`, `ipconfig/ifconfig` to diagnose and resolve it. Document your troubleshooting steps.

Hints: Intentionally misconfigure a network setting on one VM, then try to access it from another. Focus on the tools used for diagnosis.

Phase 2: Threat Detection, Analysis & Incident Response Fundamentals

Days 31-60: Developing skills in identifying and responding to security incidents.

🎯 Phase 2 Goals

Log Analysis SIEM Concepts Incident Response Life Cycle Malware Analysis (Basic) Cyber Threat Intelligence

Week 5: Log Management & Analysis

  • Understand different types of logs (Windows Event Logs, Syslog, application logs).
  • Learn log collection and aggregation principles.
  • Practice analyzing security event logs to identify suspicious activity.
  • Introduction to Security Information and Event Management (SIEM) concepts.
  • Understand the importance of time synchronization in logging.
  • Familiarize yourself with common log formats.
  • Learn about log retention policies and best practices.
  • Explore basic scripting for log parsing (e.g., simple Grep/PowerShell).
Syslog Windows Event Logs Log Aggregation Basic SIEM

Task: Analyze Windows Event Logs for failed login attempts.

Generate failed login attempts on your Windows VM and then analyze the security event logs to identify the source and frequency of these attempts.

Week 6: SIEM & Alerting

  • Deep dive into SIEM functionalities (correlation rules, dashboards, reporting).
  • Understand how SIEMs aid in threat detection.
  • Learn about common SIEM alerts and their interpretation.
  • Explore basic use cases for SIEM in a security operations center (SOC).
  • Familiarize yourself with incident ticketing systems and their role.
  • Understand the concept of false positives and false negatives in alerts.
  • Learn to prioritize alerts based on severity and impact.
  • Research open-source SIEM alternatives (e.g., ELK Stack, Splunk Free).
SIEM (Splunk/ELK) Alerting Correlation Rules SOC Operations

Task: Design a simple SIEM correlation rule.

Based on your log analysis, propose a correlation rule that would trigger an alert for a specific suspicious activity (e.g., multiple failed logins followed by a successful login from a different IP).

Week 7: Incident Response Life Cycle

  • Understand the six phases of the Incident Response Life Cycle (Preparation, Identification, Containment, Eradication, Recovery, Post-Incident Analysis).
  • Learn about incident classification and prioritization.
  • Familiarize yourself with incident response playbooks and runbooks.
  • Understand the importance of communication during an incident.
  • Explore basic forensic concepts for incident investigation.
  • Learn about data preservation and chain of custody.
  • Understand the legal and regulatory implications of security incidents.
  • Research common incident response frameworks (e.g., NIST SP 800-61).
Incident Response NIST IR Framework Playbooks Forensics Basics

Task: Develop a mini incident response plan.

Outline a basic incident response plan for a simulated phishing attack targeting an employee. Detail the steps from identification to recovery.

Week 8: Threat Intelligence & Vulnerability Assessment

  • Understand the role of Cyber Threat Intelligence (CTI) in security.
  • Learn about different CTI feeds and sources.
  • Familiarize yourself with threat indicators (IOCs, TTPs).
  • Explore advanced vulnerability assessment techniques beyond basic scanning.
  • Understand penetration testing basics (reconnaissance, scanning, exploitation).
  • Learn about common vulnerabilities (OWASP Top 10 for web applications).
  • Practice analyzing threat reports and advisories.
  • Understand the difference between vulnerability management and patch management.
Threat Intelligence Vulnerability Assessment OWASP Top 10 Penetration Testing (Basic)

Task: Create a threat intelligence brief on a current threat actor.

Choose a known threat actor group (e.g., APT28, Lazarus Group). Research their common TTPs, targets, and recent activities, then summarize your findings.

🚀 Milestone 2 Achievement

You can now actively participate in security monitoring, understand the fundamentals of SIEM, identify suspicious activities through log analysis, and comprehend the full lifecycle of incident response. You're ready to apply these skills in practical scenarios.

Projects After Phase 2

Choose one of the following projects to apply your intermediate knowledge:

Simulated Phishing Attack Analysis

Craft a realistic simulated phishing email and analyze the potential impact if an employee clicked it. Outline detection methods and containment strategies.

Hints: Focus on social engineering techniques, email headers, and how a SIEM might flag such an event.

Build a Basic Log Monitoring System (ELK/Splunk Free)

Set up a simple ELK Stack (Elasticsearch, Logstash, Kibana) or Splunk Free instance in your virtual lab. Ingest logs from one of your VMs and create a basic dashboard to monitor security events.

Hints: Use official documentation, focus on getting logs flowing and creating simple visualizations.

Incident Response Playbook for a Ransomware Attack

Develop a detailed, step-by-step playbook for responding to a ransomware attack. Include identification, containment, eradication, recovery, and post-incident analysis steps.

Hints: Consider backup strategies, network isolation, communication protocols, and forensic evidence collection.

Analyze a Publicly Available Packet Capture (PCAP)

Download a publicly available malicious PCAP file (e.g., from VirusTotal Intelligence or a security blog). Use Wireshark to analyze it, identify the attack, and extract relevant IOCs.

Hints: Look for unusual traffic patterns, known malicious signatures, and attempt to reconstruct network conversations.

Days 61-90: Refining skills and preparing for real-world scenarios.

Cloud Security Basics Security Automation Compliance & Governance Advanced Threat Hunting Security Tooling Proficiency

  • Understand cloud-native security tools and services.
  • Learn about data security in the cloud.
  • Explore container security basics (Docker, Kubernetes).

Cloud Security AWS/Azure/GCP Basics Shared Responsibility IAM

Task: Outline a basic cloud security policy for an organization.

Develop a high-level security policy for data storage and access in a hypothetical cloud environment (e.g., S3 buckets in AWS). Focus on best practices for access control and encryption.

Week 10: Security Automation & Scripting

  • Introduction to basic scripting for security tasks (Python for network scanning/parsing).
  • Understand Security Orchestration, Automation, and Response (SOAR) concepts.
  • Explore API security and its importance in automation.
  • Learn how to automate basic incident response tasks.
  • Familiarize yourself with common security APIs.
  • Practice writing simple scripts to interact with security tools or logs.
  • Understand the benefits and risks of security automation.
  • Explore how playbooks are integrated into SOAR platforms.
Python Scripting SOAR APIs Automation

Task: Write a Python script to scan for open ports.

Develop a simple Python script that can scan a target IP address for open ports (similar to a basic Nmap scan). Focus on basic socket programming.

Week 11: Compliance, Governance & Risk Management

  • Understand common security frameworks and regulations (NIST CSF, ISO 27001, GDPR, HIPAA).
  • Learn about risk assessment methodologies (identifying, analyzing, mitigating risks).
  • Explore security auditing and compliance reporting.
  • Familiarize yourself with security governance principles.
  • Understand the role of a security analyst in maintaining compliance.
  • Learn about incident reporting requirements based on regulations.
  • Explore third-party risk management.
  • Understand business continuity and disaster recovery planning.
NIST CSF ISO 27001 GDPR/HIPAA Risk Management

Task: Conduct a mini-risk assessment for a hypothetical scenario.

Choose a common organizational asset (e.g., a web server). Identify potential threats, vulnerabilities, and assess the risk level. Propose mitigation strategies.

Week 12: Advanced Threat Hunting & Career Development

  • Introduction to proactive threat hunting techniques.
  • Learn about using MITRE ATT&CK framework for threat analysis.
  • Explore advanced persistent threats (APTs) and their characteristics.
  • Practice analyzing complex security incidents.
  • Review and refine your resume and LinkedIn profile.
  • Prepare for security analyst interviews (common questions, technical assessments).
  • Network with cybersecurity professionals.
  • Identify areas for continued learning and specialization.
Threat Hunting MITRE ATT&CK APTs Career Prep

Partner with a peer or use an AI tool to simulate a security analyst interview. Focus on technical questions and scenario-based responses. Get feedback and refine your answers.

You have successfully navigated the 90-day roadmap, gaining a comprehensive understanding of security analyst responsibilities, mastering essential tools, and building practical skills in threat detection, analysis, and response. You are now well-prepared to embark on a successful career as a Security Analyst!

Capstone Projects

Complete one of these projects to demonstrate your comprehensive understanding and practical skills:

End-to-End Incident Response Simulation

Simulate a multi-stage attack (e.g., phishing leading to malware infection, then data exfiltration) in your virtual lab. Act as the security analyst, detect the attack, respond, contain, eradicate, and recover. Document every step.

Hints: Use tools like Metasploit (responsibly and ethically), Wireshark, your SIEM. Focus on the complete IR lifecycle.

Build a Security Monitoring Dashboard

Using your chosen SIEM (ELK Stack, Splunk Free, or similar), create a comprehensive security dashboard that visualizes key security metrics, alerts, and log data. Include metrics on failed logins, suspicious network activity, and critical vulnerabilities.

Hints: Focus on creating actionable insights, clear visualizations, and meaningful alerts for an analyst.

Develop a Personal Threat Intelligence Feed

Create a system (even a simple script or manual process) to collect and analyze threat intelligence from various open-source feeds. Identify emerging threats and write a daily threat briefing for a week.

Hints: Use sources like Abuse.ch, AlienVault OTX, government advisories. Focus on summarizing and prioritizing threats.

Web Application Security Assessment (Basic)

Set up a vulnerable web application (e.g., OWASP Juice Shop, Damn Vulnerable Web App) in your lab. Use basic web vulnerability scanning tools (e.g., Burp Suite Community, OWASP ZAP) to find and report common vulnerabilities like XSS and SQL Injection.

Hints: Understand HTTP methods, common web attacks, and how these tools identify them. Report findings clearly.

Project Ideas

Practical projects to build your portfolio and solidify your skills at various levels

Basic

  • **Virtual Lab Setup:** Create a multi-VM environment (Windows, Linux, Kali) and configure basic network connectivity.
  • **Nmap Scanning & Reporting:** Scan your home network (with permission) or virtual lab, identifying active devices, open ports, and services. Generate a report.
  • **Wireshark Packet Analysis:** Capture and analyze traffic from a simple web Browse session or a ping command, identifying different protocols.
  • **Log Review Exercise:** Analyze Windows Event Logs for security events (e.g., account lockouts, service failures).
  • **Basic Firewall Rules:** Configure simple inbound/outbound firewall rules on a Windows or Linux VM to block specific traffic.
  • **Password Policy Implementation:** Document and implement a strong password policy on a local user account.
  • **Antivirus Scan & Report:** Run a full scan with a free antivirus solution and interpret the results.
  • **Basic Vulnerability Scan:** Use OpenVAS to scan one of your lab VMs and understand the vulnerability report.
  • **Threat Research Brief:** Pick a recent cyberattack and write a concise summary (what happened, impact, mitigation).
  • **Security Best Practices Checklist:** Create a simple checklist for securing a home computer or small office network.

Intermediate

  • **SIEM Log Ingestion & Dashboard:** Set up a local ELK Stack or Splunk Free instance and ingest logs from your lab VMs. Create a security dashboard.
  • **Incident Response Playbook (Phishing):** Develop a detailed playbook for responding to a phishing email incident, from detection to recovery.
  • **Custom Alerting Rule:** Configure a SIEM alert for a specific suspicious activity (e.g., brute-force attack attempts).
  • **Malware Sandbox Analysis (Basic):** Use a free online sandbox (e.g., Any.Run) to analyze a suspicious file and extract IOCs.
  • **Network Intrusion Detection with Snort/Suricata:** Deploy Snort or Suricata in your lab to detect common attack signatures.
  • **Vulnerability Remediation Plan:** Based on a vulnerability scan report, create a prioritized remediation plan.
  • **Cloud Security Group Configuration:** In a free tier cloud account (AWS/Azure), configure security groups/network security groups to restrict access to a virtual machine.
  • **Python Script for Log Parsing:** Write a Python script to parse a custom log file and extract specific security-relevant information.
  • **Basic Threat Hunting Exercise:** Use log data to proactively search for indicators of compromise that wouldn't typically trigger an automated alert.
  • **Security Policy Draft:** Draft a basic acceptable use policy or password policy for a small company.

Advanced

  • **Full Attack Simulation & IR:** Simulate a multi-stage attack (e.g., initial access, lateral movement, data exfiltration) and perform full incident response, documenting each phase.
  • **Custom SIEM Correlation Rules:** Develop complex correlation rules in your SIEM to detect sophisticated attack patterns.
  • **Automated Incident Response Script:** Create a Python script that automates a simple IR task, like blocking an IP on a firewall in response to an alert.
  • **Forensic Image Analysis:** Acquire a forensic image of a compromised virtual machine (using FTK Imager) and analyze it for artifacts of the attack.
  • **Web Application Penetration Test (Basic):** Perform a basic penetration test on a vulnerable web application using Burp Suite or OWASP ZAP, documenting findings and recommendations.
  • **Cloud Security Posture Management (CSPM) Review:** Research and apply best practices for securing a cloud environment (e.g., CIS Benchmarks for AWS/Azure).
  • **Endpoint Detection & Response (EDR) Simulation:** Research how EDR tools work and simulate how they would detect and respond to a specific threat.
  • **Cyber Threat Intelligence Fusion:** Integrate multiple threat intelligence feeds into your SIEM or a custom script to enhance detection capabilities.
  • **Threat Model a Small Application:** Apply a threat modeling methodology (e.g., STRIDE) to a simple application to identify potential security weaknesses.
  • **Security Awareness Training Module:** Develop a short training module for non-technical users on a common security threat (e.g., phishing).

What Next

Your journey doesn't end here! Continuous learning is key in cybersecurity.

1. Specialize and Deepen Your Expertise

  • **Threat Hunting:** Dive deeper into proactive threat discovery and analysis.
  • **Digital Forensics & Incident Response (DFIR):** Become an expert in investigating and responding to complex breaches.
  • **Cloud Security:** Focus on securing cloud environments (AWS, Azure, GCP).
  • **GRC (Governance, Risk, and Compliance):** Understand and implement security frameworks and regulatory requirements.
  • **Application Security:** Learn about securing software development lifecycles (SDLC) and web application vulnerabilities.
  • **Security Architecture:** Design and implement secure systems and networks.
  • **Identity and Access Management (IAM):** Specialize in managing digital identities and access controls.
  • **OT/ICS Security:** Focus on securing operational technology and industrial control systems.
  • **Malware Analysis:** Deeper dive into reverse engineering and understanding malware behavior.
  • **Red Teaming/Penetration Testing:** Learn offensive security to better understand defensive strategies (requires significant ethical considerations).

2. Advance Your Certifications

  • **(ISC)² CISSP:** The gold standard for experienced security professionals.
  • **GIAC Certifications (GSEC, GCIH, GCFA, GCFE):** Highly respected for specific technical domains.
  • **Offensive Security Certified Professional (OSCP):** If you wish to pivot into offensive security.
  • **CISM (Certified Information Security Manager):** For management-focused roles.
  • **CCSP (Certified Cloud Security Professional):** For cloud security expertise.
  • **Vendor-Specific Certifications:** Dive deep into specific technologies like Splunk, CrowdStrike, Carbon Black, etc.
  • **CRISC (Certified in Risk and Information Systems Control):** For risk management roles.
  • **CISA (Certified Information Systems Auditor):** For auditing roles.
  • **CompTIA CASP+:** Advanced-level security certification.
  • **Practical Network Penetration Tester (PNPT):** A hands-on penetration testing certification.

3. Contribute to the Community & Stay Current

  • **Attend Conferences and Webinars:** Stay updated on emerging threats and technologies.
  • **Participate in CTFs (Capture The Flag):** Continuously hone your technical skills in a competitive environment.
  • **Read Industry Blogs and Reports:** Follow leading security researchers and threat intelligence sources.
  • **Contribute to Open Source Projects:** Gain practical experience and give back to the community.
  • **Mentor Others:** Share your knowledge and solidify your understanding by teaching.
  • **Write Blog Posts or Articles:** Document your learnings and share your insights.
  • **Join Professional Organizations:** (e.g., ISACA, (ISC)², InfraGard).
  • **Pursue Advanced Degrees:** Consider a Master's in Cybersecurity or a related field.
  • **Stay Hands-On:** Continue practicing with lab environments and real-world scenarios.
  • **Network Continuously:** Build relationships with other professionals for knowledge sharing and career opportunities.
