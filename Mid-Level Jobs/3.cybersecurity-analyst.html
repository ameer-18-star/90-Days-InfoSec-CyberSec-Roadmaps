90-Day Roadmap For "Cybersecurity Analyst"

This 90-day roadmap is designed to equip you with the foundational knowledge and practical skills necessary to excel as a Cybersecurity Analyst. From understanding core concepts to hands-on incident response, this guide will set you on the path to becoming a vigilant defender of digital assets.

Phase 1: Foundational Knowledge & Network Security

Days 1-30: Building Your Cybersecurity Base

🎯 Phase 1 Goals

Networking Fundamentals Operating Systems Basics Security Principles Basic Linux Commands Introduction to Cryptography

Week 1: Core Networking & OS Concepts

  • Understand TCP/IP Model and OSI Model.
  • Learn about common networking protocols (HTTP, DNS, DHCP, SMTP, FTP).
  • Explore basic router and switch functionalities.
  • Familiarize yourself with Windows and Linux operating system structures.
  • Learn command-line basics (CMD, PowerShell for Windows; Bash for Linux).
  • Understand user management and file permissions in both OS types.
  • Introduction to Virtualization (VirtualBox/VMware).
TCP/IP OSI Model Linux Windows

Setup Your Lab Environment:

Set up a virtual lab with Kali Linux and a Windows target machine (e.g., Windows 10/Server 2019) using VirtualBox or VMware Workstation Player.

Week 2: Security Fundamentals & Threat Landscape

  • Grasp the CIA Triad (Confidentiality, Integrity, Availability).
  • Understand common cyber threats (Malware, Phishing, DoS/DDoS, SQL Injection, XSS).
  • Learn about attack vectors and attack surfaces.
  • Introduction to vulnerability vs. exploit.
  • Explore basic security controls (firewalls, IDS/IPS, antivirus).
  • Understand the concept of defense-in-depth.
  • Familiarize with security policies and procedures.
CIA Triad Malware Phishing Firewalls

Threat Identification Exercise:

Research and document the top 5 cybersecurity threats impacting businesses today, detailing their impact and common prevention methods.

Week 3: Network Security & Basic Cryptography

  • Deep dive into firewall rules and configurations.
  • Understand Network Address Translation (NAT) and VPNs.
  • Learn about common network scanning tools (Nmap fundamentals).
  • Introduction to encryption, hashing, and digital signatures.
  • Explore symmetric and asymmetric encryption concepts.
  • Understand Public Key Infrastructure (PKI) basics.
  • Study secure communication protocols (SSL/TLS).
Nmap VPN SSL/TLS Cryptography

Nmap Scan & Report:

Perform basic Nmap scans on your lab's target machine and interpret the results to identify open ports and services. Document your findings.

Week 4: Introduction to Security Operations & Incident Response

  • Understand the role of a Security Operations Center (SOC).
  • Learn about the Incident Response life cycle (Preparation, Identification, Containment, Eradication, Recovery, Post-Incident Analysis).
  • Familiarize with security logging and monitoring.
  • Introduction to Security Information and Event Management (SIEM) concepts.
  • Understand basic log analysis from Windows Event Viewer and Linux syslog.
  • Explore concepts of alerts, false positives, and true positives.
  • Learn about security baselines and configuration management.
SOC Incident Response SIEM (concept) Log Analysis

Basic Log Analysis:

Generate some common logs in your lab environment (e.g., failed logins) and analyze them using Windows Event Viewer or Linux `grep` commands.

🎯 Milestone 1 Achievement

You've successfully built a foundational understanding of cybersecurity concepts, networking, operating systems, and introduced yourself to security operations principles. You can now articulate basic security threats and their mitigation strategies.

Projects After Phase 1

These projects will solidify your understanding of Phase 1 concepts.

Network Topology Map

Draw a detailed network diagram of your home network, identifying devices, IP addresses, and security considerations.

Hints: Use tools like draw.io or Visio. Include firewall placement and Wi-Fi security type.

Operating System Hardening Checklist

Create a checklist of 10 essential security hardening steps for a Windows 10 and a Kali Linux machine.

Hints: Focus on user accounts, strong passwords, updates, firewall, and unnecessary services.

Basic Packet Analysis

Using Wireshark in your lab, capture traffic during a simple web Browse session and identify HTTP, DNS, and TCP packets.

Hints: Filter traffic, observe source/destination IPs, and port numbers.

Cryptographic Concept Explanation

Write a short explanation (1-2 pages) differentiating symmetric and asymmetric encryption, providing real-world examples for each.

Hints: Consider TLS/SSL for asymmetric and AES for symmetric.

Phase 2: Intermediate Security Concepts & Tooling

Days 31-60: Deepening Your Analytical Skills

🎯 Phase 2 Goals

Vulnerability Management Endpoint Security Web Application Security Security Incident Handling Python Scripting Basics

Week 5: Vulnerability Management & Scanning

  • Understand the vulnerability management life cycle.
  • Learn about common vulnerability scanning tools (Nessus, OpenVAS concepts).
  • Analyze vulnerability reports and prioritize remediation efforts.
  • Understand Common Vulnerabilities and Exposures (CVE) and Common Vulnerability Scoring System (CVSS).
  • Introduction to penetration testing concepts vs. vulnerability scanning.
  • Explore secure configuration management best practices.
Nessus (concept) OpenVAS (concept) CVE CVSS

Vulnerability Scan Simulation:

Research how to conduct a basic vulnerability scan using OpenVAS (or a similar free tool) in your lab and interpret a sample report.

Week 6: Endpoint Security & Malware Analysis Basics

  • Understand Endpoint Detection and Response (EDR) and Antivirus (AV) functionalities.
  • Learn about host-based firewalls and intrusion prevention.
  • Introduction to basic malware types and their characteristics.
  • Familiarize with static and dynamic malware analysis concepts.
  • Understand file integrity monitoring (FIM) and application whitelisting.
  • Explore the principle of least privilege for users and applications.
EDR Antivirus Malware Analysis Least Privilege

Malware Behavior Research:

Choose a recent, prominent malware (e.g., a specific ransomware strain) and research its attack vector, execution, and impact.

Week 7: Web Application Security & OWASP Top 10

  • Understand common web application vulnerabilities (OWASP Top 10).
  • Learn about SQL Injection, Cross-Site Scripting (XSS), and Broken Authentication.
  • Explore basic concepts of web proxies (Burp Suite Community Edition basics).
  • Understand input validation and secure coding practices.
  • Familiarize with the importance of secure development life cycles (SDLC).
  • Introduction to API security considerations.
OWASP Top 10 SQL Injection XSS Burp Suite (basics)

OWASP Top 10 Analysis:

Pick two vulnerabilities from the OWASP Top 10 and explain how they work and how to mitigate them.

Week 8: Security Incident Handling & Basic Scripting

  • Deepen your understanding of the Incident Response phases with practical examples.
  • Learn how to identify indicators of compromise (IOCs).
  • Practice analyzing security alerts and triaging incidents.
  • Introduction to basic Python scripting for security tasks (e.g., parsing logs, simple network tools).
  • Understand forensic imaging concepts (basic `dd` command in Linux).
  • Explore basic security automation concepts.
Incident Handling IOCs Python (basics) Forensics (concept)

Simple Python Log Parser:

Write a basic Python script that reads a log file and extracts specific information (e.g., IP addresses, error messages).

🚀 Milestone 2 Achievement

You've moved beyond foundational concepts to understand intermediate security domains. You can identify and explain common vulnerabilities, understand basic incident handling procedures, and have started to automate simple tasks with scripting.

Projects After Phase 2

These projects will allow you to apply your intermediate knowledge.

Vulnerability Report Analysis

Obtain a sample vulnerability scan report (publicly available or simulated) and write a summary identifying critical vulnerabilities and suggested remediations.

Hints: Focus on CVSS scores and business impact.

Endpoint Security Policy Draft

Draft a basic endpoint security policy for a small business, covering antivirus, patching, and data encryption.

Hints: Consider common attack vectors targeting endpoints.

Web Application Attack Scenario

Describe a scenario where a SQL Injection attack could occur and outline the steps an attacker would take and how to prevent it.

Hints: Explain how user input is misused.

Incident Response Playbook Outline

Create a high-level outline for an incident response playbook for a phishing attack, including initial steps, containment, and communication.

Hints: Think about who needs to be involved and what information needs to be gathered.

Phase 3: Advanced Topics, Compliance & Career Readiness

Days 61-90: Refining Your Expertise and Preparing for the Field

🎯 Phase 3 Goals

Security Monitoring & SIEM Cloud Security Basics Compliance & Regulations Advanced Threat Detection Career Development & Interview Prep

Week 9: Advanced Security Monitoring & SIEM Operations

  • Dive deeper into SIEM systems (Splunk, ELK Stack concepts).
  • Learn about correlation rules and alert tuning in a SIEM.
  • Understand threat intelligence platforms (TIPs) and their integration with SIEM.
  • Explore security automation and orchestration (SOAR) concepts.
  • Practice creating security dashboards and reports.
  • Familiarize with network flow data analysis (NetFlow/IPFIX).
SIEM (Splunk/ELK) Threat Intelligence SOAR Log Correlation

SIEM Use Case Development:

Propose three practical use cases for a SIEM system in a corporate environment (e.g., detecting brute-force attacks, unauthorized access).

Week 10: Cloud Security Fundamentals & IAM

  • Understand fundamental concepts of cloud computing (IaaS, PaaS, SaaS).
  • Learn about shared responsibility model in the cloud.
  • Explore basic cloud security best practices (AWS, Azure, GCP concepts).
  • Deep dive into Identity and Access Management (IAM) in both on-premise and cloud environments.
  • Understand principles of secure cloud configurations.
  • Familiarize with data security in the cloud.
Cloud Security IAM AWS/Azure (concepts) Shared Responsibility

Cloud Security Checklist:

Create a basic security checklist for deploying a web application in a public cloud environment (e.g., securing EC2 instances, S3 buckets).

Week 11: Governance, Risk, Compliance (GRC) & Security Frameworks

  • Understand the importance of GRC in cybersecurity.
  • Learn about common compliance standards (GDPR, HIPAA, PCI DSS concepts).
  • Familiarize with cybersecurity frameworks (NIST CSF, ISO 27001 concepts).
  • Understand risk assessment methodologies and risk treatment options.
  • Explore security audits and assessments.
  • Learn about business continuity and disaster recovery planning.
GRC NIST CSF ISO 27001 GDPR/HIPAA (concepts)

Compliance Overview:

Choose one cybersecurity framework (e.g., NIST CSF) and provide a brief overview of its core functions and why it's important.

Week 12: Career Readiness, Advanced Threats & Specialization

  • Refine your resume and LinkedIn profile for cybersecurity analyst roles.
  • Practice common cybersecurity interview questions.
  • Explore advanced persistent threats (APTs) and their characteristics.
  • Introduction to threat hunting concepts.
  • Understand current and emerging cybersecurity trends (AI in security, OT/IoT security).
  • Identify potential specialization areas within cybersecurity (e.g., GRC, Cloud Security, Incident Response).
Career Prep APTs Threat Hunting Industry Trends

Mock Interview / Resume Review:

Perform a mock interview with a peer or mentor, or critically review and refine your resume based on job descriptions.

🏆 Final Achievement

Congratulations! You've completed a rigorous 90-day roadmap. You possess a strong understanding of cybersecurity principles, practical skills in various domains, and are well-prepared to enter or advance within the cybersecurity analyst field. Your ability to apply knowledge, analyze incidents, and understand the broader security landscape makes you a valuable asset.

Recommended Resources

Essential learning platforms and materials for your journey

Top Books

  • CompTIA Security+ Study Guide by Mike Chapple & David Seidl
  • Practical Packet Analysis by Chris Sanders
  • Blue Team Handbook: SOC Analyst's Guide by Nadean Tanner
  • Applied Cryptography by Bruce Schneier
  • The Phoenix Project by Gene Kim, Kevin Behr, George Spafford (for understanding IT operations)

Best Learning Platforms

  • **TryHackMe:** Hands-on labs for various cybersecurity topics.
  • **Hack The Box:** Advanced penetration testing labs and challenges.
  • **Cybrary:** Free and paid courses on a wide range of cybersecurity domains.
  • **Coursera / edX:** Courses from reputable universities (e.g., Google Cybersecurity Professional Certificate, IBM Cybersecurity Analyst Professional Certificate).
  • **Sans.org Reading Room:** Free whitepapers and articles from SANS Institute.
  • **OWASP Foundation:** Resources for web application security.
  • **YouTube Channels:** David Bombal, NetworkChuck, John Hammond, The Cyber Mentor.

Professional Certifications

  • **CompTIA Security+:** Excellent entry-level certification.
  • **CompTIA CySA+ (Cybersecurity Analyst+):** Builds on Security+, focusing on analytical skills.
  • **(ISC)² CCSP (Certified Cloud Security Professional):** For cloud security roles (consider after foundational cloud knowledge).
  • **EC-Council CEH (Certified Ethical Hacker):** More offensive, but valuable for understanding attacker mindset.
  • **Google Cybersecurity Professional Certificate:** Entry-level, practical skills focused.

Communities & Forums

  • **Reddit:** r/cybersecurity, r/blueteam, r/netsec.
  • **Stack Exchange:** Information Security Stack Exchange.
  • **Discord/Slack Channels:** Many cybersecurity communities have active channels.
  • **LinkedIn Groups:** Join cybersecurity professional groups.
  • **Local Meetups:** Look for local cybersecurity meetups or OWASP chapters.
  • **Conferences:** Attend virtual or local cybersecurity conferences (e.g., DEF CON, Black Hat, RSA Conference - even just watching talks online).

Recommended Tools

Essential tools and platforms for your journey

Operating Systems & Virtualization

  • **Kali Linux:** Penetration testing and security auditing OS.
  • **Windows (VM):** For analyzing Windows-specific threats and understanding enterprise environments.
  • **VirtualBox / VMware Workstation Player:** For creating and managing virtual lab environments.

Network & Traffic Analysis

  • **Wireshark:** Network protocol analyzer.
  • **Nmap:** Network scanner and security auditor.
  • **tcpdump:** Command-line packet analyzer.
  • **Netcat (nc):** Network utility for reading from and writing to network connections.

Vulnerability & Exploitation (Ethical Hacking Context)

  • **OpenVAS / Greenbone Community Edition:** Vulnerability scanner.
  • **Metasploit Framework (basics):** For understanding exploits and payloads.
  • **Burp Suite Community Edition:** Web vulnerability scanner and proxy.

Log Management & Incident Response

  • **Splunk (Free/Trial):** SIEM for log aggregation and analysis.
  • **ELK Stack (Elasticsearch, Logstash, Kibana):** Open-source alternative for log management.
  • **Autopsy / FTK Imager Lite:** Basic forensic analysis tools.
  • **Sysinternals Suite (for Windows):** Advanced system utilities for troubleshooting and security analysis.

Project Ideas

Hands-on projects to build your portfolio and reinforce learning

Basic

  • **Home Network Security Audit:** Identify devices, open ports, and suggest security improvements.
  • **Password Policy Implementation:** Document and implement a strong password policy for a local system.
  • **Basic Firewall Configuration:** Set up and configure a software firewall on a test machine to block specific traffic.
  • **Malware Signature Creation:** Research a simple malware and try to identify a unique signature (e.g., hash, string) for it.
  • **Network Scanning Report:** Conduct a detailed Nmap scan of your lab network and create a report of findings.

Intermediate

  • **Incident Response Tabletop Exercise:** Simulate a small-scale incident (e.g., a suspected virus infection) and walk through your response steps.
  • **Web Vulnerability Scan & Report:** Use a tool like Burp Suite Community Edition to scan a vulnerable web application (e.g., OWASP Juice Shop) and document findings.
  • **Custom Log Monitoring Script:** Write a Python script to monitor a specific log file for suspicious activities and send alerts.
  • **Active Directory Basics (Lab):** Set up a small Active Directory environment in your VM lab and explore user/group management and security policies.
  • **Cloud Security Best Practices Deployment:** Deploy a simple web server in a free tier cloud account (AWS, Azure) and apply basic security best practices.

Advanced

  • **Threat Hunt Simulation:** Develop a hypothesis for a threat and use available logs (simulated or real from a lab) to "hunt" for evidence.
  • **Build a Security Awareness Program:** Design a short security awareness training module for employees on phishing or strong passwords.
  • **Implement a SIEM Home Lab:** Set up Splunk or ELK Stack to collect logs from multiple lab systems and create custom alerts/dashboards.
  • **Capture The Flag (CTF) Participation:** Participate in beginner/intermediate-level CTFs to apply a wide range of skills.
  • **Security Policy Development:** Draft a comprehensive security policy for a specific area (e.g., Data Loss Prevention, Remote Access) for a hypothetical company.

Expert

  • **Develop a custom IOC Scanner:** Create a script to scan systems for specific indicators of compromise based on recent threat intelligence.
  • **Automate Incident Response Tasks:** Use Python or PowerShell to automate parts of an incident response workflow (e.g., isolating a compromised host).
  • **Cloud Security Assessment:** Conduct a mock security assessment of a cloud environment, identifying misconfigurations and vulnerabilities.
  • **Contribution to Open Source Security Project:** Contribute code or documentation to an open-source security tool.
  • **Simulated Attack & Defense:** Plan and execute a controlled attack in your lab environment and then respond as a cybersecurity analyst, documenting both sides.

What Next: Beyond 90 Days

Continuous learning and specialization are key in cybersecurity

1. Specialization

  • **Incident Response & Forensics:** Dive deeper into memory forensics, malware analysis, and advanced incident handling.
  • **Security Architecture & Engineering:** Learn about designing secure systems, secure development life cycles, and security controls implementation.
  • **Cloud Security:** Focus on specific cloud platforms (AWS, Azure, GCP) and their native security services.
  • **GRC & Audit:** Specialize in compliance frameworks, risk management, and security auditing.
  • **Penetration Testing / Red Teaming:** Transition to offensive security to understand attacker methodologies in depth.

2. Advanced Certifications

  • **GIAC Certifications (GSEC, GCIH, GCIA):** Highly respected and practical certifications from SANS.
  • ** Offensive Security Certified Professional (OSCP):** If you lean towards offensive security.
  • **Certified Information Systems Security Professional (CISSP):** For experienced professionals, covering a broad range of security domains.
  • **Azure/AWS Security Speciality Certifications:** For deep cloud security expertise.

3. Continuous Learning

  • **Stay Updated:** Follow cybersecurity news, blogs (e.g., SANS Internet Storm Center, Krebs on Security), and threat intelligence feeds.
  • **Participate in CTFs & Bug Bounties:** Keep your skills sharp and learn new techniques.
  • **Networking:** Engage with the cybersecurity community through conferences, meetups, and online forums.
  • **Read Research Papers:** Stay informed about cutting-edge security research and emerging threats.

4. Contribute & Mentor

  • **Share Knowledge:** Blog about your learning, contribute to open-source projects, or mentor newcomers.
  • **Build Your Brand:** Create a professional online presence (GitHub, LinkedIn) showcasing your projects and skills.
  • **Seek Advanced Roles:** Look for Senior Cybersecurity Analyst, Security Engineer, or Incident Responder positions.
