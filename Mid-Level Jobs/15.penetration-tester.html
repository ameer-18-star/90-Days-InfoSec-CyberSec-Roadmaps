90-Day Roadmap For "Penetration Tester"

           

Become a proficient penetration tester with this intensive 90-day roadmap. This guide covers foundational knowledge, essential tools, and practical skills to prepare you for real-world engagements.

           
               
           
       
       
                       
               

Phase 1: Foundation & Networking

                Days 1-30: Build a strong cybersecurity and networking base.            
           
               

🎯 Phase 1 Goals

               
                    Networking Basics                     Linux Fundamentals                     Basic Scripting (Python/Bash)                     Virtualization                     Security Concepts                
           
           
               
                   

Week 1: Networking & OS Foundations

                   
                           
  • Understand TCP/IP model, common protocols (HTTP, DNS, SMTP, SSH).
    •                        
  • Learn about IP addressing, subnetting, and routing.
    •                        
  • Set up a virtual lab environment (VirtualBox/VMware).
    •                        
  • Install Kali Linux and Metasploitable 2.
    •                        
  • Basic Linux commands (navigation, file manipulation, permissions).
    •                        
  • Introduction to shell scripting (Bash basics).
    •                    
                   
                        TCP/IP                         Linux                         Virtualization                         Bash                    
                   
                       

Task at the end of week: Network Discovery Script

                       

Write a Bash script to ping a range of IP addresses and identify active hosts on your lab network.

                   
               
               
                   

Week 2: Linux Deep Dive & Scripting

                   
                           
  • Advanced Linux commands (grep, awk, sed, cron, package management).
    •                        
  • Understand Linux file system hierarchy and user management.
    •                        
  • Learn Python fundamentals: variables, data types, control flow, functions.
    •                        
  • Explore basic network tools: `ping`, `traceroute`, `netstat`, `ipconfig/ifconfig`.
    •                        
  • Introduction to common security terms and concepts (vulnerability, exploit, payload).
    •                    
                   
                        Linux Admin                         Python                         Network Utilities                    
                   
                       

Task at the end of week: Basic Port Scanner

                       

Develop a simple Python script to scan for open ports on a target machine in your lab.

                   
               
               
                   

Week 3: Web Basics & Information Gathering

                   
                           
  • Understand HTTP/HTTPS, web servers (Apache, Nginx), and web applications.
    •                        
  • Introduction to common web vulnerabilities (OWASP Top 10 overview).
    •                        
  • Learn about active vs. passive reconnaissance.
    •                        
  • Utilize tools like `whois`, `nslookup`/`dig`, and Shodan for public information gathering.
    •                        
  • Explore OSINT (Open Source Intelligence) techniques.
    •                    
                   
                        Web Protocols                         OSINT                         OWASP                         Shodan                    
                   
                       

Task at the end of week: Target Reconnaissance Report

                       

Conduct passive reconnaissance on a target website (e.g., a non-profit organization's public site) and compile a report of gathered information (domains, subdomains, public IPs, technologies).

                   
               
               
                   

Week 4: Vulnerability Scanning & Analysis

                   
                           
  • Understand vulnerability scanning methodologies and tools.
    •                        
  • Learn to use Nmap for host discovery, port scanning, and service version detection.
    •                        
  • Explore vulnerability scanners like OpenVAS/Nessus (community edition).
    •                        
  • Analyze scan results and identify potential vulnerabilities.
    •                        
  • Introduction to common misconfigurations.
    •                    
                   
                        Nmap                         OpenVAS                         Vulnerability Analysis                    
                   
                       

Task at the end of week: Scan and Document Metasploitable 2

                       

Perform a comprehensive Nmap scan and a vulnerability scan on your Metasploitable 2 VM. Document all identified open ports, services, and vulnerabilities.

                   
               
           
           
               

🎯 Milestone 1 Achievement

               

You've established a solid foundation in networking, Linux, basic scripting, and initial reconnaissance techniques. You can now set up your own lab, identify active hosts, scan for open ports, and conduct basic vulnerability assessments.

           
                       
               

Projects After Phase 1

               

Apply your foundational skills to these hands-on projects.

               
                   
                       

Network Mapper Tool

                       

Develop a Python script that combines network discovery (ping sweep) with basic port scanning using the `socket` module. Output results to a file.

                        Hints: Use `subprocess` for `ping`, `socket` for port checks. Handle exceptions.                    
                   
                       

Vulnerability Lab Setup & Initial Scan

                       

Set up a small home lab with at least two VMs: Kali Linux and another vulnerable machine (e.g., OWASP Broken Web Apps, a deliberately vulnerable Linux VM). Perform initial Nmap and OpenVAS scans.

                        Hints: Document your setup process and initial findings. Screenshots are a plus.                    
                   
                       

Basic Web Recon Script

                       

Write a Python script that takes a domain as input and performs `whois` lookup, `dig` for DNS records, and attempts to resolve common subdomains (e.g., www, mail, blog) using a wordlist.

                        Hints: Use `python-whois`, `dnspython`, and `requests` libraries.                    
               
           
           
                       
               

Phase 2: Exploitation & Web Application Testing

                Days 31-60: Deep dive into common vulnerabilities and exploitation techniques.            
           
               

🎯 Phase 2 Goals

               
                    Metasploit                     Web App Attacks                     Burp Suite                     SQL Injection                     Cross-Site Scripting (XSS)                
           
           
               
                   

Week 5: Exploitation with Metasploit

                   
                           
  • Introduction to the Metasploit Framework.
    •                        
  • Understand exploits, payloads, and auxiliary modules.
    •                        
  • Practice exploiting common vulnerabilities (e.g., EternalBlue, MS08-067) on Metasploitable 2.
    •                        
  • Learn about Meterpreter and post-exploitation basics.
    •                        
  • Understand the basics of shellcoding and buffer overflows (conceptual).
    •                    
                   
                        Metasploit                         Exploitation                         Meterpreter                    
                   
                       

Task at the end of week: Exploit Metasploitable 2 services

                       

Successfully exploit at least three different services on Metasploitable 2 using Metasploit, gaining a Meterpreter session on each.

                   
               
               
                   

Week 6: Web Application Proxy & Basic Attacks

                   
                           
  • Master Burp Suite Community Edition: Proxy, Repeater, Intruder.
    •                        
  • Understand common web application attack vectors (Injection, Broken Authentication, XSS).
    •                        
  • Practice identifying and exploiting basic SQL Injection vulnerabilities (manual and using SQLmap).
    •                        
  • Explore Cross-Site Scripting (XSS) types (Reflected, Stored, DOM-based).
    •                    
                   
                        Burp Suite                         SQL Injection                         XSS                         SQLmap                    
                   
                       

Task at the end of week: OWASP Juice Shop Level Completion

                       

Complete at least 5-7 challenges on OWASP Juice Shop related to SQL Injection, XSS, and broken authentication using Burp Suite.

                   
               
               
                   

Week 7: Advanced Web & Privilege Escalation

                   
                           
  • Explore other web vulnerabilities: CSRF, SSRF, File Upload vulnerabilities, XML External Entity (XXE).
    •                        
  • Understand the concept of privilege escalation (Linux & Windows).
    •                        
  • Learn about common privilege escalation techniques (sudo misconfigurations, SUID binaries, kernel exploits, weak service permissions).
    •                        
  • Introduction to common post-exploitation enumeration tools (LinPEAS, WinPEAS).
    •                    
                   
                        Privilege Escalation                         Web Vulnerabilities                         LinPEAS                    
                   
                       

Task at the end of week: Privilege Escalation on a CTF Box

                       

Solve a beginner-to-intermediate Capture The Flag (CTF) box that involves Linux or Windows privilege escalation techniques on platforms like Hack The Box (starting point) or TryHackMe.

                   
               
               
                   

Week 8: Active Directory & Pivoting Basics

                   
                           
  • Introduction to Active Directory concepts (users, groups, domains, trusts).
    •                        
  • Learn about common Active Directory attacks (Pass-the-Hash, Kerberoasting - conceptual).
    •                        
  • Understand the concept of pivoting and tunneling.
    •                        
  • Practice basic pivoting techniques using SSH or Chisel in your lab environment.
    •                        
  • Basic understanding of client-side attacks (e.g., phishing awareness).
    •                    
                   
                        Active Directory                         Pivoting                         SSH Tunneling                    
                   
                       

Task at the end of week: Simple AD Lab Setup & Enumeration

                       

Set up a simple Active Directory lab (e.g., using a Windows Server VM as a DC and a Windows client VM). Practice basic enumeration using tools like `enum4linux` or `CrackMapExec` from your Kali Linux machine.

                   
               
           
           
               

🚀 Milestone 2 Achievement

               

You can now actively exploit common vulnerabilities using Metasploit and manual techniques. You're proficient with Burp Suite for web application testing, and you understand the fundamentals of privilege escalation and basic Active Directory attacks.

           
                       
               

Projects After Phase 2

               

Solidify your exploitation skills with these practical scenarios.

               
                   
                       

Full Exploitation Chain (CTF)

                       

Solve a more complex CTF box that requires initial foothold, enumeration, web exploitation (e.g., SQLi or LFI), and privilege escalation to gain root/administrator access.

                        Hints: Document each step. Look for well-regarded "OSCP-like" boxes on HTB/THM.                    
                   
                       

Automated Web Vulnerability Scanner (Basic)

                       

Write a Python script that takes a URL and attempts to find common vulnerabilities like reflected XSS or basic SQL injection by injecting simple payloads into URL parameters.

                        Hints: Use `requests` library. Check for specific error messages or echoed input.                    
                   
                       

Active Directory Attack Simulation (Basic)

                       

On your AD lab, attempt a simple attack like user enumeration or a "null session" attack if applicable, and explore tools like `ldapsearch` or `rpcclient` to gather information.

                        Hints: Focus on understanding AD structure and enumeration before exploitation.                    
               
           
           
                       
               

Phase 3: Reporting, Advanced Techniques & Specialization

                Days 61-90: Refine skills, learn reporting, and explore specialized areas.            
           
               

🎯 Phase 3 Goals

               
                    Professional Reporting                     Adversary Simulation                     Cloud Security Basics                     Mobile/API Pentesting Intro                     Capture The Flag (CTF) Practice                
           
           
               
                   

Week 9: Reporting & Methodology

                   
                           
  • Understand the structure of a penetration test report (executive summary, technical findings, recommendations).
    •                        
  • Learn about common pentesting methodologies (OSSTMM, PTES, NIST 800-115).
    •                        
  • Practice writing clear, concise, and actionable vulnerability descriptions.
    •                        
  • Introduction to Red Teaming vs. Pentesting concepts.
    •                        
  • Explore advanced Linux post-exploitation (e.g., cron jobs, scheduled tasks, persistence).
    •                    
                   
                        Reporting                         PTES                         Post-Exploitation                    
                   
                       

Task at the end of week: Draft a Sample Penetration Test Report

                       

Based on your Metasploitable 2 or CTF engagements, draft a concise penetration test report including an executive summary, findings with CVSS scores, and recommendations for remediation.

                   
               
               
                   

Week 10: Cloud & Container Security Basics

                   
                           
  • Introduction to cloud computing concepts (IaaS, PaaS, SaaS).
    •                        
  • Understand common cloud security risks (misconfigurations, IAM issues).
    •                        
  • Basic AWS/Azure/GCP security concepts (e.g., S3 bucket misconfigurations, security groups).
    •                        
  • Introduction to container security (Docker, Kubernetes basics).
    •                        
  • Explore API security fundamentals and common API vulnerabilities (OWASP API Security Top 10).
    •                    
                   
                        Cloud Security                         Container Security                         API Security                    
                   
                       

Task at the end of week: Cloud Vulnerability Research

                       

Research a common cloud security vulnerability (e.g., exposed S3 bucket, misconfigured Azure storage account) and write a short explanation of how it works and potential exploitation methods.

                   
               
               
                   

Week 11: Wireless & Mobile Security (Intro)

                   
                           
  • Understand wireless network fundamentals (Wi-Fi standards, WPA2/3).
    •                        
  • Introduction to common wireless attacks (deauthentication, Evil Twin, WPA2 cracking - conceptual).
    •                        
  • Basic mobile application security concepts (Android/iOS).
    •                        
  • Learn about reverse engineering basics and static/dynamic analysis of binaries (conceptual).
    •                        
  • Practice more complex CTF challenges, focusing on a wider range of attack types.
    •                    
                   
                        Wireless Security                         Mobile Security                         Reverse Engineering (Intro)                    
                   
                       

Task at the end of week: Analyze a Simple Android Application

                       

Use `apktool` and `jadx` (or similar) to decompile a simple Android application (e.g., a vulnerable one from a lab) and identify hardcoded secrets or insecure API calls.

                   
               
               
                   

Week 12: Capstone Project & Career Prep

                   
                           
  • Simulate a full penetration test engagement on a complex lab environment (e.g., a multi-machine CTF or a realistic vulnhub VM).
    •                        
  • Focus on systematic methodology: Recon, Scanning, Exploitation, Post-Exploitation, Reporting.
    •                        
  • Refine your reporting skills and create a professional-grade report for your capstone project.
    •                        
  • Prepare for job interviews: common technical questions, explaining methodologies, ethical considerations.
    •                        
  • Review foundational concepts and strengthen weak areas.
    •                    
                   
                        Full Pentest Lifecycle                         Professionalism                         Interview Prep                    
                   
                       

Task at the end of week: Comprehensive Pentest Simulation & Report

                       

Perform a complete penetration test on a complex vulnerable machine or lab environment. Document every step, from initial enumeration to privilege escalation, and produce a high-quality, professional pentest report.

                   
               
           
           
               

🏆 Final Achievement

               

Congratulations! You've completed an intensive 90-day roadmap to become a highly capable penetration tester. You possess the foundational knowledge, practical skills, and reporting expertise to identify and exploit vulnerabilities across various systems and applications.

           
                       
               

Capstone Projects & Continued Learning

               

Continue honing your skills with these advanced projects and continuous learning strategies.

               
                   
                       

Advanced CTF Series

                       

Tackle more challenging CTF challenges on platforms like Hack The Box (retired machines), TryHackMe (Offensive Security path), or VulnHub, focusing on scenarios involving less common exploit techniques, evasion, or complex chains.

                        Hints: Focus on understanding underlying mechanisms rather than just tool usage.                    
                   
                       

Develop a Custom Exploit

                       

Identify a simple vulnerable application (e.g., a C program with a buffer overflow) and write a custom exploit for it from scratch, understanding registers, shellcode, and memory layout.

                        Hints: Start with Stack-based Buffer Overflows. Resources like "Protostar" or "Smashed Stack For Fun and Profit" are good.                    
                   
                       

Bug Bounty Participation (Responsible Disclosure)

                       

Start participating in bug bounty programs on platforms like HackerOne or Bugcrowd. Begin with simple programs or focus on specific vulnerability types you excel at.

                        Hints: Read program rules carefully. Start with public programs and low-criticality findings.

What's Next: Your Journey Continues

                The world of cybersecurity is constantly evolving. Here's how to stay ahead.            
           
               
                   

1. Specialize and Deepen Knowledge

                   
                           
  • **Web Application Security:** Dive deeper into advanced web vulnerabilities, API security, and specific frameworks.
    •                        
  • **Network Penetration Testing:** Master advanced network attacks, segmentation bypasses, and wireless hacking.
    •                        
  • **Cloud Penetration Testing:** Focus on AWS, Azure, or GCP specific attack vectors and tools.
    •                        
  • **Mobile Penetration Testing:** Learn more about Android and iOS app reverse engineering and security testing.
    •                        
  • **Red Teaming:** Explore adversary simulation, advanced persistent threats (APTs), and stealth techniques.
    •                    
               
               
                   

2. Advanced Certifications

                   
                           
  • Offensive Security Certified Professional (OSCP) - Highly recommended for practical skills.
    •                        
  • Offensive Security Web Assessor (OSWA) / Exploit Developer (OSED).
    •                        
  • GIAC Penetration Tester (GPEN) / GIAC Web Application Penetration Tester (GWAPT).
    •                        
  • Certified Red Team Professional (CRTP) / Certified Red Team Expert (CRTE).
    •                    
               
               
                   

3. Continuous Learning & Contribution

                   
                           
  • **Stay Updated:** Read security blogs, research papers, and follow industry news.
    •                        
  • **Practice Regularly:** Consistently engage with CTFs and vulnerable labs.
    •                        
  • **Network:** Attend conferences (e.g., Black Hat, Defcon, BSides), webinars, and meetups.
    •                        
  • **Contribute:** Share your knowledge by writing blog posts, giving talks, or contributing to open-source tools.
    •
