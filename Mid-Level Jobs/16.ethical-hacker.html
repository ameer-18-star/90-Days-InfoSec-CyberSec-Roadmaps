90-Day Roadmap For "Ethical Hacker"

Master the art of ethical hacking and fortify your cybersecurity skills.

Phase 1: Foundation

Days 1-30: Build your core knowledge in networking, operating systems, and basic security concepts.

🎯 Phase 1 Goals

Networking Fundamentals Linux Basics Security Concepts Virtualization Basic Scripting

Week 1: Networking & Linux Fundamentals

  • Understand TCP/IP model, common protocols (HTTP, DNS, FTP, SSH).
  • Learn basic Linux commands (navigation, file manipulation, permissions).
  • Set up a virtual lab environment (VirtualBox/VMware with Kali Linux and a target OS like Metasploitable).
  • Familiarize yourself with network scanning basics (ping, traceroute).
TCP/IP Linux CLI VirtualBox Kali Linux

Task at the end of Week 1:

Set up your virtual hacking lab with Kali Linux and Metasploitable 2. Practice basic network connectivity and file operations within Linux.

Week 2: Deeper Networking & Kali Tools Intro

  • Explore subnetting, routing, and network services.
  • Dive deeper into Linux: package management, service control, user management.
  • Introduction to command-line network tools: `netstat`, `ip a`, `route`.
  • First look at Kali Linux tools: `nmap` for basic host discovery and port scanning.
Subnetting Linux Services nmap Wireshark (passive observation)

Task at the end of Week 2:

Perform a comprehensive Nmap scan on your Metasploitable VM to identify open ports and services. Document your findings.

Week 3: Scripting Basics & Info Gathering

  • Learn Python fundamentals (variables, data types, loops, conditionals, functions).
  • Understand basic information gathering techniques (OSINT).
  • Explore common web technologies (HTTP/S, HTML, CSS, JavaScript).
  • Use `whois`, `dig`, and basic `nslookup` commands.
Python OSINT HTTP/S whois

Task at the end of Week 3:

Write a simple Python script to perform a basic web request and parse a small piece of information from the response header.

Week 4: Introduction to Vulnerability Analysis

  • Understand common vulnerabilities (OWASP Top 10 introduction).
  • Learn about vulnerability scanning tools like OpenVAS/Nessus (community version).
  • Basic understanding of different attack types (reconnaissance, scanning, gaining access).
  • Introduction to basic exploitation concepts (what is an exploit, payload).
OWASP Top 10 OpenVAS Vulnerability Scanning Exploit Concepts

Task at the end of Week 4:

Run a vulnerability scan on your Metasploitable VM using OpenVAS and analyze the generated report, identifying critical vulnerabilities.

🎯 Milestone 1 Achievement

You've successfully built a foundational understanding of networking, Linux, basic scripting, and the initial phases of ethical hacking (reconnaissance and vulnerability scanning).

Projects After Phase 1

Apply your newly acquired foundational knowledge through these hands-on projects.

Network Mapper

Develop a Python script that scans a local network and identifies active hosts using ARP or ICMP requests.

Hints: Use `scapy` library for packet crafting; explore network device discovery.

Linux Hardening Script

Write a Bash script to automate basic security configurations on a Linux system (e.g., disable unused services, change default SSH port).

Hints: Research common Linux security best practices; use `systemctl` and `ufw`.

Basic Web Scraper for OSINT

Create a Python script that extracts specific information (e.g., emails, phone numbers) from publicly accessible websites.

Hints: Utilize `requests` and `BeautifulSoup` libraries; be mindful of `robots.txt`.

Vulnerability Report Analysis

Take the OpenVAS report from Week 4 and write a detailed executive summary and technical breakdown of the top 3 vulnerabilities, including potential impacts.

Hints: Focus on clarity, conciseness, and actionable recommendations.

Phase 2: Deep Dive into Exploitation

Days 31-60: Understand common attack vectors, exploit frameworks, and web application vulnerabilities.

🎯 Phase 2 Goals

Metasploit Framework Web Application Hacking Buffer Overflows (Basic) Post-Exploitation Network Sniffing & Analysis

Week 5: Exploitation with Metasploit

  • Master Metasploit Framework: `msfconsole` basics, modules (exploit, payload, auxiliary).
  • Practice exploiting known vulnerabilities on Metasploitable 2.
  • Understand the concept of shells (reverse, bind) and staging.
  • Introduction to encoding and bypassing basic antivirus (conceptual).
Metasploit Exploitation Payloads Meterpreter

Task at the end of Week 5:

Successfully exploit at least three different vulnerabilities on Metasploitable 2 using Metasploit and gain a Meterpreter session. Document each step.

Week 6: Web Application Hacking - Part 1

  • In-depth study of OWASP Top 10 vulnerabilities (Injection, Broken Authentication).
  • Learn to use Burp Suite (Community Edition) for intercepting and modifying web traffic.
  • Practice SQL Injection techniques (manual and using SQLmap).
  • Explore Cross-Site Scripting (XSS) and its different types.
Burp Suite SQL Injection XSS SQLmap

Task at the end of Week 6:

Find and exploit a SQL Injection vulnerability on a deliberately vulnerable web application (e.g., DVWA, bWAPP). Extract data from the database.

Week 7: Web Application Hacking - Part 2 & Password Attacks

  • Cross-Site Request Forgery (CSRF), Security Misconfigurations.
  • File Upload vulnerabilities, Insecure Direct Object References.
  • Brute-force and dictionary attacks using tools like Hydra and Hashcat.
  • Understanding password hashing and salting.
CSRF File Upload Vulns Hydra Hashcat

Task at the end of Week 7:

Perform a dictionary attack against a vulnerable login page using Hydra. Also, identify and attempt a malicious file upload on a test web application.

Week 8: Post-Exploitation & Privilege Escalation

  • Techniques for maintaining access (backdoors, persistent shells).
  • Linux and Windows privilege escalation methods (kernel exploits, misconfigurations).
  • Lateral movement concepts within a compromised network.
  • Basic forensics and anti-forensics concepts (e.g., clearing logs).
Privilege Escalation Lateral Movement Persistence Linux PrivEsc Tools

Task at the end of Week 8:

After gaining a low-privilege shell on a target, execute a privilege escalation technique to obtain root/administrator access.

🚀 Milestone 2 Achievement

You've gained practical experience in exploiting systems and web applications, understanding how attackers gain and maintain access, and escalating privileges.

Projects After Phase 2

Solidify your intermediate hacking skills by tackling these realistic scenarios.

Multi-Stage Attack Simulation

Design and execute a multi-stage attack on a lab environment, starting with reconnaissance, exploiting a vulnerability, and then performing privilege escalation.

Hints: Use different tools for each stage; document your kill chain.

Web Application Penetration Test Report

Conduct a simulated penetration test on a vulnerable web application (e.g., OWASP Juice Shop) and write a professional-style report detailing findings, risks, and recommendations.

Hints: Follow a standard pentest report structure (executive summary, technical findings, remediation).

Custom Metasploit Module (Basic)

Attempt to create a very simple Metasploit auxiliary module or exploit module for a trivial vulnerability (e.g., a simple FTP banner grabber).

Hints: Study existing Metasploit modules; understand Ruby basics if attempting an exploit.

Network Sniffing & Credential Harvesting

Set up a scenario to capture network traffic (e.g., on an unencrypted login) using Wireshark or tcpdump and extract credentials.

Hints: Understand network segmentation and clear-text protocols.

Phase 3: Advanced Concepts & Specialization

Days 61-90: Explore advanced topics, specialize, and refine your skills for real-world engagements.

🎯 Phase 3 Goals

Wireless Hacking Mobile/API Hacking (Intro) Cloud Security (Intro) Reporting & Ethics Bug Bounty / CTF Strategies

Week 9: Wireless & Network Device Hacking

  • Understand Wi-Fi security (WEP, WPA/WPA2, WPA3).
  • Practice Wi-Fi cracking techniques (Aircrack-ng suite, Evil Twin attacks).
  • Introduction to network device security (routers, switches - basic configuration flaws).
  • Learn about sniffing and spoofing attacks (ARP Spoofing, DNS Spoofing).
Wireless Hacking Aircrack-ng ARP Spoofing Network Devices

Task at the end of Week 9:

Attempt to crack a WPA2-PSK network in your lab using Aircrack-ng. Conduct an ARP spoofing attack between two virtual machines.

Week 10: Advanced Web & API Hacking / Mobile (Intro)

  • Server-Side Request Forgery (SSRF), XML External Entity (XXE).
  • API hacking fundamentals (Postman, Burp Suite for API testing).
  • Introduction to mobile application security (Android/iOS basics, common vulnerabilities).
  • Explore deserialization vulnerabilities and their impact.
SSRF API Security Mobile App Security XXE

Task at the end of Week 10:

Identify and attempt to exploit an SSRF vulnerability on a vulnerable web application. Explore an intentionally vulnerable mobile app (e.g., OWASP GoatDroid).

Week 11: Cloud Security & Red Teaming Concepts

  • Introduction to cloud security (AWS, Azure basics for security assessments).
  • Common cloud misconfigurations (S3 buckets, IAM roles).
  • Understand the difference between penetration testing and red teaming.
  • Explore advanced persistent threats (APTs) and threat intelligence.
Cloud Security AWS/Azure Basics Red Teaming Threat Intelligence

Task at the end of Week 11:

Research common AWS S3 bucket misconfigurations and how they can be exploited. Create a small write-up on a recent APT attack.

Week 12: Capture The Flag (CTF) & Bug Bounties

  • Participate in beginner to intermediate CTF challenges (TryHackMe, Hack The Box).
  • Understand the ethical and legal aspects of bug bounty programs.
  • Practice writing professional penetration test reports and remediation plans.
  • Continuous learning strategies: staying updated with new vulnerabilities and tools.
CTF Bug Bounty Reporting Continuous Learning

Task at the end of Week 12:

Complete at least two "easy" or "medium" rated machines on TryHackMe or Hack The Box. Draft a professional bug bounty submission report for a hypothetical vulnerability.

🏆 Final Achievement

You have completed a rigorous 90-day journey, transforming into a capable ethical hacker with a strong understanding of fundamental to advanced attack techniques and defensive strategies. Congratulations!

Capstone Projects After Phase 3

These projects combine all the skills you've learned, preparing you for real-world challenges.

Comprehensive Pentest Simulation

Conduct a full penetration test on a complex lab environment (e.g., a multi-tiered web application with a backend database and multiple network services). Document the entire process from reconnaissance to reporting.

Hints: Emphasize stealth, persistence, and detailed reporting. Consider pivoting between systems.

Automated Vulnerability Scanner (Enhancement)

Build upon your scripting knowledge to create a more advanced Python-based vulnerability scanner that can detect specific types of web application vulnerabilities (e.g., XSS, SQLi) in a given URL.

Hints: Research web parsing techniques; implement basic vulnerability checks based on input. Use `requests` library.

CTF Grand Challenge

Participate in a more challenging, time-limited CTF event or a specific "hard" machine on platforms like Hack The Box, aiming for root access and comprehensive flag collection.

Hints: Focus on critical thinking and combining multiple attack vectors.

Research & Exploit Development

Choose a recent, publicly disclosed vulnerability (e.g., a CVE) and research its technical details. If feasible and safe, attempt to replicate the exploit in your lab environment or write a conceptual exploit script.

Hints: Start with simpler vulnerabilities; understand proof-of-concept code and security advisories.

Project Ideas

Hands-on projects to reinforce your learning and build a portfolio.

Basic

  • Build a personal hacking lab with isolated VMs.
  • Create a simple Python port scanner.
  • Perform a comprehensive Nmap scan on your home network (with permission!).
  • Analyze network traffic for common protocols using Wireshark.
  • Set up a firewall on a Linux VM and test its rules.

Intermediate

  • Perform a full penetration test on a vulnerable web application (e.g., DVWA, bWAPP) and document all findings.
  • Develop a script to automate a specific reconnaissance task (e.g., gathering subdomains).
  • Exploit a vulnerable Windows machine using Metasploit and pivot to another system.
  • Practice privilege escalation on various Linux machines (search for "Linux PrivEsc CTF").
  • Analyze and re-create a simple web-based exploit from a public CVE.

Advanced

  • Participate in a competitive Capture The Flag (CTF) event.
  • Find and report a legitimate bug on a public bug bounty program (start with disclosure policies).
  • Develop a custom tool for a specific security task (e.g., a web fuzzer, a custom payload generator).
  • Contribute to an open-source security project.
  • Design and implement a secure network architecture for a small business in a simulated environment.

Expert

  • Attempt to reverse engineer a piece of malware or a binary.
  • Develop an exploit for a zero-day vulnerability (in a safe, isolated environment).
  • Conduct a red team exercise against a simulated corporate network.
  • Research and present on an advanced cybersecurity topic (e.g., supply chain attacks, AI in security).
  • Mentor aspiring ethical hackers and share your knowledge.

What Next: Beyond 90 Days

Your journey doesn't end here. Continuous learning is key in cybersecurity.

1. Specialization

  • **Web Application Security:** Dive deep into specific frameworks (e.g., NodeJS, React), advanced bypass techniques, and cloud-native web apps.
  • **Network Penetration Testing:** Focus on Active Directory, industrial control systems (ICS/SCADA), and advanced network segmentation bypasses.
  • **Reverse Engineering & Malware Analysis:** Learn assembly language, debuggers (IDA Pro, Ghidra), and sandbox environments.
  • **Mobile Security:** Master Android and iOS app analysis, static and dynamic analysis, and mobile API testing.
  • **Cloud Security:** Specialize in securing specific cloud providers (AWS, Azure, GCP) and their native security services.

2. Advanced Certifications

  • **OSCE3 (Offensive Security Certified Expert):** For exploit development and advanced topics.
  • **CRTP/CRTE (Certified Red Team Professional/Expert):** Focus on Active Directory and red teaming.
  • **SANS Certifications (e.g., GWAPT, GPEN, GXPN):** Industry-leading, highly technical certifications.
  • **CRTO (Certified Red Team Operator):** Another highly practical red teaming certification.

3. Contribute & Engage

  • **Open Source Projects:** Contribute to tools, frameworks, or security research.
  • **Bug Bounty Programs:** Continuously hunt for vulnerabilities on live systems (with authorization).
  • **CTF Competitions:** Participate regularly to keep your skills sharp and learn new techniques.
  • **Conferences & Meetups:** Attend industry events (online or in-person) to network and learn from experts.
  • **Mentorship:** Guide newcomers to the field, solidifying your own understanding.

4. Stay Current

  • **Follow Security News:** Subscribe to industry blogs, news feeds (e.g., The Hacker News, Dark Reading).
  • **Read Research Papers:** Keep up with academic and industry security research.
  • **Practice Daily:** Dedicate time each day or week to hands-on practice, even if it's just a short lab.
  • **Learn New Languages/Technologies:** As technology evolves, so do attack surfaces. Keep learning new programming languages and emerging technologies (e.g., blockchain, IoT, AI security).
