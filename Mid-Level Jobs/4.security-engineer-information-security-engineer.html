90-Day Roadmap For "Security Engineer / Information Security Engineer"

A comprehensive 90-day plan to build a strong foundation and practical skills as a Security Engineer, focusing on core concepts, hands-on application, and advanced topics.

Phase 1: Foundational Knowledge & Core Concepts

Days 1-30: Build a robust understanding of security fundamentals.

🎯 Phase 1 Goals

Networking Basics Operating Systems Security Basic Cryptography Security Principles Linux Fundamentals

Week 1: Networking & Protocols

  • Understand TCP/IP model, OSI model.
  • Learn common protocols: HTTP/S, DNS, SMTP, SSH, FTP.
  • Explore network devices: Routers, Switches, Firewalls.
  • Grasp subnetting and IP addressing.
  • Introduction to Wireshark for packet analysis.
  • Familiarize yourself with basic network reconnaissance tools.
  • Understand common network attacks (e.g., sniffing, spoofing).
  • Basic firewall concepts and rules.
Wireshark TCP/IP OSI Model Basic Networking Tools

Task: Network Reconnaissance & Analysis

Set up a virtual network (e.g., using VirtualBox/VMware) and use tools like Nmap and Wireshark to map the network and analyze traffic patterns. Identify open ports and services.

Week 2: Operating Systems Security (Linux & Windows)

  • **Linux:** User/group management, file permissions (chmod, chown), sudo.
  • **Linux:** Basic shell scripting (Bash).
  • **Windows:** Active Directory fundamentals, NTFS permissions.
  • **Windows:** Understanding Group Policy Objects (GPOs).
  • Patch management concepts for both OS.
  • Understanding system logs and event viewers.
  • Basic hardening techniques for Linux and Windows.
  • Familiarize yourself with common OS vulnerabilities.
Linux CLI Windows Server Bash Active Directory

Task: OS Hardening & User Management

Harden a fresh Linux VM (e.g., Ubuntu Server) by applying secure configurations, managing users/groups, and configuring firewall rules. Perform similar basic hardening on a Windows VM.

Week 3: Cryptography & Security Principles

  • Understand Symmetric vs. Asymmetric encryption.
  • Explore Hashing algorithms (MD5, SHA).
  • Learn about Digital Signatures and Certificates (PKI basics).
  • Key security principles: Confidentiality, Integrity, Availability (CIA Triad).
  • Authentication, Authorization, Accounting (AAA).
  • Threat modeling basics (STRIDE, DREAD).
  • Understanding common security frameworks (e.g., NIST, ISO 27001 - overview).
  • Introduction to security policies and procedures.
Cryptography PKI CIA Triad NIST Framework (Conceptual)

Task: Implementing Basic Encryption

Use OpenSSL to generate a key pair, encrypt and decrypt a file, and create a self-signed certificate. Document the steps and explain the cryptographic concepts involved.

Week 4: Web Application Security Fundamentals

  • Understand common web vulnerabilities: OWASP Top 10 (Injection, XSS, Broken Auth).
  • Learn how web applications work (client-server model, HTTP methods).
  • Introduction to web proxies like Burp Suite Community Edition.
  • Understanding session management and cookie security.
  • Basic understanding of secure coding principles.
  • Familiarize yourself with common web servers (Apache, Nginx, IIS).
  • Understand basic concepts of APIs and their security implications.
  • Explore the concept of Content Security Policy (CSP).
OWASP Top 10 Burp Suite HTTP/S Web Basics

Task: Basic Web Vulnerability Scanning

Set up a vulnerable web application (e.g., OWASP Juice Shop, DVWA) and use Burp Suite to identify basic vulnerabilities like XSS and SQL Injection (without exploiting them fully).

🎯 Milestone 1 Achievement

You've built a solid foundational understanding of networking, operating systems, basic cryptography, and web application security. You can analyze basic network traffic, harden OS configurations, and identify fundamental web vulnerabilities.

Projects After Phase 1

These projects will help solidify your understanding of Phase 1 concepts through practical application.

Home Lab Setup

Build a small virtual lab with a pfSense/OPNsense firewall, a Linux server, and a Windows client. Configure basic network segmentation and firewall rules.

Hints: Use VirtualBox/VMware, research pfSense/OPNsense setup guides, practice setting static IPs and basic NAT rules.

Secure Shell Scripting

Write Bash scripts to automate common security tasks like log file analysis, user account auditing, or basic system health checks on a Linux server.

Hints: Focus on secure coding practices (e.g., input validation), use `grep`, `awk`, `sed` for log parsing, and `crontab` for scheduling.

Web Application Security Checklist

Develop a basic security checklist for a simple web application based on OWASP Top 10. Identify potential risks and suggest mitigation strategies for each item.

Hints: Focus on common vulnerabilities, research secure coding practices for common web frameworks, consider input validation and output encoding.

Active Directory Basics Audit

On a Windows Server VM, create users and groups, assign permissions, and then audit these configurations to ensure they adhere to the principle of least privilege.

Hints: Use built-in Windows tools like `dsquery`, `Get-ADUser`, `Get-ADGroup` in PowerShell, and Event Viewer for auditing.

Phase 2: Deeper Dives & Practical Application

Days 31-60: Apply foundational knowledge to real-world scenarios and tools.

🎯 Phase 2 Goals

Vulnerability Management Security Information & Event Management (SIEM) Cloud Security Fundamentals Identity & Access Management (IAM) Basic Python for Security

Week 5: Vulnerability Management & Scanning

  • Understand the vulnerability lifecycle (discovery, assessment, remediation, verification).
  • Learn about common vulnerability scoring systems (CVSS).
  • Hands-on with vulnerability scanners: Nessus (trial), OpenVAS, Nmap Scripting Engine (NSE).
  • Practice analyzing vulnerability reports and prioritizing findings.
  • Understand patch management processes and best practices.
  • Introduction to penetration testing concepts (recon, scanning, exploitation - high level).
  • Explore public vulnerability databases (CVE, NVD).
  • Differentiate between vulnerability scanning and penetration testing.
Nessus/OpenVAS CVSS Nmap NSE CVE/NVD

Task: Vulnerability Assessment of a VM

Use a vulnerability scanner to scan a vulnerable VM (e.g., Metasploitable 2) and generate a report. Analyze the findings and propose remediation steps.

Week 6: Security Information & Event Management (SIEM)

  • Understand the purpose and components of a SIEM.
  • Learn about log sources: Firewall logs, OS logs, application logs.
  • Introduction to log analysis with Splunk Free or ELK Stack (Elasticsearch, Logstash, Kibana).
  • Develop basic correlation rules and alerts.
  • Understand incident response phases (preparation, identification, containment, eradication, recovery, post-incident).
  • Practice creating basic dashboards for security monitoring.
  • Familiarize yourself with common attack signatures in logs.
  • Learn about threat intelligence feeds and their integration with SIEM.
Splunk/ELK Stack Log Analysis Incident Response (IR) Logstash

Task: Basic Log Collection & Analysis

Set up a basic ELK stack (or use Splunk Free) and ingest logs from a Linux server. Create dashboards to visualize security events and identify suspicious activities.

Week 7: Cloud Security Fundamentals (AWS/Azure)

  • Understand shared responsibility model in cloud.
  • Core cloud security concepts: IAM, network security groups, security policies.
  • Introduction to AWS/Azure foundational security services (e.g., AWS S3 security, Azure VNets).
  • Understand basic cloud resource hardening.
  • Familiarize yourself with cloud logging and monitoring (e.g., CloudTrail, Azure Monitor).
  • Explore common cloud attack vectors.
  • Understand the concept of Infrastructure as Code (IaC) and its security implications.
  • Learn about securing containers (Docker basics).
AWS/Azure Basics Shared Responsibility Model IAM Docker (Basic)

Task: Secure Cloud Resource Deployment

Deploy a simple web server in AWS EC2 or Azure VM, ensuring it adheres to security best practices (e.g., strict security group rules, IAM roles, logging enabled).

Week 8: Identity & Access Management (IAM) & Scripting for Security

  • Deep dive into IAM concepts: Authentication, Authorization, MFA, SSO.
  • Understand different authentication methods (Kerberos, OAuth, OpenID Connect).
  • **Python for Security:** Learn basic Python scripting for automating tasks.
  • Use Python to parse logs, interact with APIs (e.g., retrieve security data), or perform simple network scans.
  • Introduction to Privilege Access Management (PAM).
  • Understand directory services beyond Active Directory (LDAP).
  • Explore the principle of least privilege in practice.
  • Learn about secret management solutions.
Python IAM Concepts MFA/SSO LDAP

Task: Python Script for Log Parsing or API Interaction

Write a Python script to parse a security log file (e.g., Apache access logs) for specific patterns (e.g., failed login attempts, suspicious IPs) or interact with a public security API to retrieve threat intelligence.

🚀 Milestone 2 Achievement

You can now conduct basic vulnerability assessments, understand and work with SIEM systems for log analysis, grasp fundamental cloud security concepts, and utilize Python for basic security automation. You're bridging the gap between theoretical knowledge and practical tooling.

Projects After Phase 2

These projects will further enhance your practical skills and connect different security domains.

Automated Vulnerability Scanning & Reporting

Integrate a vulnerability scanner (e.g., OpenVAS) with a simple Python script to automate scanning of target VMs and generate a concise report in a human-readable format.

Hints: Explore API documentation of your chosen scanner, use Python libraries for file I/O and data formatting.

SIEM Alerting & Response Playbook

Based on your SIEM setup from Week 6, create a set of custom alerts for specific attack scenarios (e.g., brute-force, port scan) and draft a basic incident response playbook for one of these alerts.

Hints: Define clear alert conditions, outline steps for verification, containment, and initial communication.

Cloud Security Audit Script

Using Python and AWS Boto3 (or Azure SDK), write a script to audit security group configurations, IAM roles, or S3 bucket policies in a test cloud account for misconfigurations.

Hints: Focus on identifying overly permissive rules or public exposures. Consult AWS/Azure security best practices.

Centralized Authentication System (Conceptual)

Design a conceptual architecture for a centralized authentication system for an organization, incorporating MFA, SSO, and integrating with a directory service. Explain your choices.

Hints: Consider protocols like SAML/OAuth, look into solutions like Okta or Azure AD, and map out user flows.

Phase 3: Advanced Concepts & Operational Security

Days 61-90: Focus on securing systems in production and preparing for real-world roles.

🎯 Phase 3 Goals

Security Architecture Compliance & Governance DevSecOps Basics Security Automation Endpoint Security

Week 9: Security Architecture & Design

  • Understand common security architecture patterns (e.g., Zero Trust, defense-in-depth).
  • Learn about network segmentation and microsegmentation.
  • Explore secure system design principles: secure by design, least privilege, separation of duties.
  • Introduction to security frameworks and standards (NIST CSF, CIS Benchmarks).
  • Understand how to read and interpret security architecture diagrams.
  • Learn about data classification and its impact on security design.
  • Explore concepts of High Availability (HA) and Disaster Recovery (DR) from a security perspective.
  • Understand supply chain security considerations.
Zero Trust Defense-in-Depth NIST CSF CIS Benchmarks

Task: Design a Secure Application Architecture

Propose a high-level security architecture for a hypothetical new web application, incorporating principles like network segmentation, IAM, and data protection. Justify your design choices.

Week 10: Compliance, Governance & Risk Management

  • Overview of major compliance frameworks: GDPR, HIPAA, PCI DSS, SOC 2.
  • Understand the role of security policies, standards, and guidelines.
  • Introduction to risk management methodologies (identification, analysis, mitigation, monitoring).
  • Learn about security audits and assessments.
  • Understand business continuity and disaster recovery planning.
  • Explore third-party risk management.
  • Familiarize yourself with common legal and regulatory requirements.
  • Understand the importance of security awareness training.
GDPR/HIPAA/PCI DSS Risk Management Security Policies Auditing

Task: Develop a Basic Risk Assessment

Conduct a simplified risk assessment for a small organizational asset (e.g., a web server). Identify potential threats, vulnerabilities, calculate risk levels, and propose mitigation strategies.

Week 11: DevSecOps & Security Automation

  • Understand DevSecOps principles and its integration into the SDLC.
  • Learn about static application security testing (SAST) and dynamic application security testing (DAST).
  • Explore security automation tools and practices (e.g., security in CI/CD pipelines).
  • Introduction to Infrastructure as Code (IaC) security (e.g., Terrascan, Checkov).
  • Understand secrets management and secure credential handling.
  • Explore container security and orchestration (Kubernetes security basics).
  • Learn about security incident automation (SOAR concepts).
  • Practice writing security-focused unit tests.
DevSecOps SAST/DAST CI/CD Security Terraform/Kubernetes (Security)

Task: Secure CI/CD Pipeline Integration (Conceptual)

Outline the steps to integrate security checks (SAST, DAST, dependency scanning) into a hypothetical CI/CD pipeline. Specify the tools and stages where these checks would occur.

Week 12: Endpoint Security & Emerging Threats

  • Understand Endpoint Detection and Response (EDR) and Antivirus (AV) solutions.
  • Learn about host-based firewalls and intrusion prevention systems.
  • Explore mobile device security and IoT security fundamentals.
  • Stay updated on emerging threats and attack techniques (e.g., AI in security, supply chain attacks).
  • Understand basic forensic principles for incident investigation.
  • Review and reinforce all previously learned concepts with practical examples.
  • Prepare for job interviews (review common security engineer interview questions).
  • Develop a personal continuous learning plan.
EDR/AV Mobile Security IoT Security Threat Intelligence

Task: Endpoint Security Policy Review

Draft a basic endpoint security policy for a small business covering areas like AV, patching, user privileges, and data encryption. Justify your policy choices based on industry best practices.

🏆 Final Achievement

Congratulations! You've completed a rigorous 90-day roadmap, acquiring a broad and deep understanding of security engineering principles, tools, and practices. You're now equipped with the skills to contribute effectively to an organization's security posture and confidently pursue Security Engineer roles.

Projects for Continued Growth After 90 Days

These projects will challenge you further and help you specialize or deepen your expertise.

Build a Security Monitoring Pipeline

Create an automated pipeline for collecting logs from various sources (e.g., cloud, on-premise), processing them, sending them to a SIEM, and generating automated alerts for specific events. Focus on scalability and efficiency.

Hints: Use tools like Fluentd/Logstash for collection, Kafka/RabbitMQ for queuing, and a robust SIEM like Splunk/Elastic.

Develop a Cloud Security Playbook

Create a detailed security playbook for deploying and securing a specific application in a cloud environment (AWS, Azure, or GCP). Include IAM, network security, data protection, and monitoring considerations.

Hints: Focus on well-architected framework security pillars, consider compliance requirements (e.g., HIPAA for healthcare apps).

Contribute to an Open-Source Security Project

Find an open-source security tool or project that interests you (e.g., related to vulnerability scanning, threat intelligence, or forensics) and contribute code, documentation, or bug reports.

Hints: Start with small contributions, engage with the community, learn Git and GitHub for collaboration.

Implement a Zero Trust Network Segment

Design and implement a small-scale Zero Trust network segment in your home lab or a cloud environment. Use a combination of microsegmentation, strong authentication, and continuous monitoring to enforce least privilege access.

Hints: Look into solutions like OpenZiti, explore NAC solutions, and focus on granular access controls.

Project Ideas to Build Your Portfolio

Hands-on projects are crucial for demonstrating your skills and understanding.

Basic Projects

  • **Home Lab Setup:** Configure a virtual network with a firewall, DNS server, and client machines.
  • **Linux Hardening Script:** Write a Bash script to automate common security configurations on a Linux server.
  • **Basic Log Analyzer (Python):** Develop a Python script to parse system logs and alert on specific events.
  • **Password Strength Checker:** Create a simple web or Python application to evaluate password strength.
  • **Network Scanner:** Build a basic network scanner using Python's `socket` library to identify open ports.

Intermediate Projects

  • **Vulnerability Management Pipeline:** Automate scanning a target VM with OpenVAS/Nessus and generate a prioritized report.
  • **SIEM Alerting System:** Set up an ELK stack to ingest logs and configure custom alerts for security events.
  • **Cloud Security Audit Script:** Write a Python script using cloud SDKs (Boto3 for AWS, Azure SDK) to audit cloud resources for misconfigurations.
  • **Secure Web Application Deployment:** Deploy a simple web application with a WAF, secure configurations, and logging enabled.
  • **Container Security Pipeline:** Integrate a container vulnerability scanner (e.g., Trivy) into a basic CI/CD pipeline for a Docker image.

Advanced Projects

  • **DevSecOps Pipeline:** Implement a full CI/CD pipeline with integrated SAST, DAST, dependency scanning, and secret scanning for a sample application.
  • **Incident Response Playbook Automation:** Use a SOAR-like approach (even with simple scripts) to automate initial response steps for a detected incident (e.g., isolating a compromised host).
  • **Zero Trust Architecture Implementation:** Design and partially implement a Zero Trust segment in a virtual lab, focusing on microsegmentation and identity-based access.
  • **Threat Intelligence Integration:** Develop a system to pull threat intelligence from multiple sources, enrich it, and integrate it with your SIEM for enhanced detection.
  • **Security Awareness Training Module:** Create a small, interactive security awareness training module focusing on common phishing attacks or secure coding practices.

Expert Level / Continuous Learning Projects

  • **Contribute to Open-Source:** Regularly contribute to a major open-source security project.
  • **Security Research:** Conduct independent research on a new attack technique or vulnerability and publish your findings.
  • **Bug Bounty Hunting:** Participate in bug bounty programs to identify and responsibly disclose vulnerabilities in real-world applications.
  • **Build Custom Security Tools:** Develop a specialized security tool in Python or Go to address a specific niche problem.
  • **Mentorship/Community Building:** Mentor aspiring security professionals or contribute to security community initiatives.

What Next: Your Journey Beyond 90 Days

Continuous learning and practical application are key to a successful career.

1. Deepen Specialization

  • **Cloud Security:** Become an expert in one cloud provider (AWS, Azure, or GCP) and specialize in their security offerings.
  • **Application Security:** Focus on secure coding, SAST/DAST, and web/API security.
  • **Security Operations (SecOps):** Master SIEM administration, incident response, and threat hunting.
  • **Network Security:** Become a guru in firewalls, IDS/IPS, and advanced network architectures.
  • **GRC (Governance, Risk, and Compliance):** Dive deeper into compliance frameworks, risk assessments, and policy development.

2. Advance Your Skillset

  • **Learn Advanced Programming:** Master Python for complex automation, Go for performance, or Rust for systems programming.
  • **Explore Advanced Linux:** Deepen your understanding of Linux internals, kernel security, and container orchestration.
  • **Dive into Reverse Engineering/Malware Analysis:** If interested in deeper threat analysis.
  • **Study Advanced Networking:** BGP, VPNs, SDN, and advanced routing protocols.
  • **Practice Threat Modeling:** Develop expertise in various threat modeling methodologies and tools.

3. Get Certified & Network

  • **Pursue Higher Certifications:** Aim for CISSP, OSCP, or cloud-specific expert-level certifications.
  • **Attend Industry Conferences:** Network with peers, learn about new trends, and discover job opportunities.
  • **Speak at Meetups/Conferences:** Share your knowledge and build your personal brand.
  • **Contribute to Open Source Projects:** Enhance your coding skills and collaborate with the community.
  • **Find a Mentor & Mentor Others:** Learn from experienced professionals and give back to the community.

4. Stay Current & Adapt

  • **Read Security Blogs & News:** Follow leading cybersecurity publications and researchers.
  • **Subscribe to Threat Intelligence Feeds:** Stay informed about the latest attack trends and vulnerabilities.
  • **Participate in CTFs (Capture The Flag):** Keep your practical skills sharp and learn new techniques.
  • **Continuously Experiment:** Set up new labs, test new tools, and break things safely to understand them better.
  • **Embrace New Technologies:** Stay curious about emerging areas like AI in security, quantum cryptography, and post-quantum cryptography.
