90-Day Roadmap For SOC Analyst – Tier 2

Accelerate your expertise in security operations, incident response, and threat detection.

Phase 1: Deepening Core Skills

Days 1-30: Establishing a Strong Baseline

🎯 Phase 1 Goals

Advanced SIEM proficiency Log Analysis Mastery Network Protocol Deep Dive Endpoint Security Understanding Incident Triage & Escalation

Week 1: Advanced SIEM & Log Management

  • Master advanced search queries, filtering, and correlation rules in a SIEM (e.g., Splunk ES, Azure Sentinel, QRadar).
  • Understand data sources and log ingestion best practices.
  • Familiarize yourself with common log formats (Syslog, JSON, XML) and their security relevance.
  • Learn to create custom dashboards and reports for effective monitoring.
  • Review and optimize existing SIEM rules to reduce false positives.
  • Explore the SIEM's threat intelligence integration capabilities.
  • Practice log review for various attack types (e.g., brute force, credential stuffing).
  • Understand the lifecycle of a security event within the SIEM.
Splunk ELK Stack Log Management Regex

Task: SIEM Rule Optimization Project

Analyze a set of high-volume alerts in your SIEM, identify common false positives, and propose/implement rule adjustments to improve accuracy by 15%.

Week 2: Network Security & Traffic Analysis

  • Deep dive into TCP/IP, DNS, HTTP/S, SMTP, SMB, and other critical protocols.
  • Learn to interpret network traffic captures using Wireshark or similar tools.
  • Understand common network attacks (e.g., DDoS, MITM, port scanning) and their signatures.
  • Explore IDS/IPS alert analysis and bypass techniques.
  • Familiarize yourself with network segmentation and firewall logs.
  • Understand netflow/IPFIX data and its use in anomaly detection.
  • Analyze network forensic artifacts for incident investigations.
  • Learn about common network security devices and their logging capabilities.
Wireshark IDS/IPS TCP/IP Firewalls

Task: Network Anomaly Detection

Given a PCAP file, identify at least three suspicious network activities and articulate your reasoning, including relevant protocols, source/destination, and potential attack vectors.

Week 3: Endpoint Security & Malware Analysis Fundamentals

  • Understand Endpoint Detection and Response (EDR) solutions (e.g., CrowdStrike, SentinelOne).
  • Learn to analyze endpoint logs (process creation, file modifications, registry changes).
  • Familiarize yourself with common malware types (ransomware, trojans, worms) and their indicators of compromise (IOCs).
  • Basic static malware analysis: string extraction, hash analysis, packed executables.
  • Understand anti-malware and antivirus technologies.
  • Learn about system hardening best practices for endpoints.
  • Explore forensic artifacts on endpoints like prefetch, MFT, and jump lists.
  • Differentiate between legitimate and malicious processes.
EDR Sysmon Volatility Malware Analysis

Task: Endpoint Compromise Scenario

Simulate an endpoint compromise (e.g., using a benign executable that mimics malware behavior). Use EDR/Sysmon logs to trace the activity and identify the initial infection vector and subsequent actions.

Week 4: Threat Intelligence & Vulnerability Management

  • Understand the different types of threat intelligence (strategic, operational, tactical).
  • Learn to leverage threat intelligence platforms (TIPs) and feeds.
  • Familiarize yourself with common vulnerability scanning tools (e.g., Nessus, OpenVAS).
  • Understand CVSS scoring and prioritize vulnerabilities.
  • Learn about common attack frameworks (MITRE ATT&CK, Kill Chain).
  • Develop skills in correlating threat intelligence with SIEM alerts.
  • Practice creating custom threat intelligence indicators.
  • Understand the importance of continuous vulnerability assessment.
MITRE ATT&CK OSINT Nessus Threat Intelligence

Task: Vulnerability Prioritization Exercise

Given a vulnerability scan report and a set of active threat intelligence feeds, prioritize the top 5 vulnerabilities that pose the most immediate risk to a hypothetical organization, justifying your choices.

🎯 Milestone 1 Achievement

You have a solid understanding of core security concepts, advanced SIEM operations, network traffic analysis, basic endpoint security, and the role of threat intelligence in a SOC. You can effectively triage and escalate common security incidents.

Projects After Phase 1

Apply your foundational knowledge to practical scenarios.

Project A: SIEM Use Case Development

Develop and implement a new SIEM correlation rule to detect a specific threat (e.g., suspicious RDP activity, multiple failed logins followed by a successful one), including testing and tuning.

Hints: Focus on a specific attack pattern, identify relevant log sources, define correlation logic, test with simulated data.

Project B: Network Traffic Investigation

Analyze a provided network packet capture (PCAP) to identify and document a simulated intrusion, detailing the attack steps and exfiltrated data (if any).

Hints: Use Wireshark filters, follow TCP streams, look for unusual ports or protocols, analyze HTTP requests/responses.

Project C: Malware Initial Triage

Perform basic static analysis on a benign executable (simulating malware) to extract IOCs (hashes, strings, imported functions) and determine its potential functionality.

Hints: Use tools like strings, pefile, VirusTotal. Do NOT run actual malware.

Project D: Threat Landscape Report

Research a recent cyberattack or APT group and create a brief report summarizing their TTPs (Tactics, Techniques, and Procedures) and recommended detection/mitigation strategies.

Hints: Refer to MITRE ATT&CK, reputable threat intelligence sources, and cybersecurity news outlets.

Phase 2: Advanced Analysis & Incident Response

Days 31-60: Developing Deeper Analytical and Response Capabilities

🎯 Phase 2 Goals

Advanced Threat Hunting Malware Reverse Engineering (Basic) Cloud Security Monitoring Scripting for Automation Digital Forensics Fundamentals

Week 5: Advanced Threat Hunting Techniques

  • Learn proactive threat hunting methodologies (hypothesis-driven, intelligence-driven, anomaly-driven).
  • Utilize advanced SIEM queries and EDR capabilities for threat hunting.
  • Understand common threat hunting frameworks and tools (e.g., Kape, Sigma rules).
  • Develop and test threat hunting playbooks.
  • Practice hunting for specific TTPs from the MITRE ATT&CK framework.
  • Identify unusual user behavior and privileged account misuse.
  • Learn about applying statistical analysis to log data for anomaly detection.
  • Familiarize yourself with open-source threat hunting resources.
Splunk Hunting Kusto Query Language (KQL) Sigma Rules MITRE ATT&CK

Task: Hypothesis-Driven Threat Hunt

Formulate a hypothesis about a potential threat in a given dataset (e.g., "Are there signs of lateral movement via SMB in the network logs?"). Develop and execute queries to prove or disprove your hypothesis, documenting your findings.

Week 6: Cloud Security Monitoring & Incident Response

  • Understand cloud service models (IaaS, PaaS, SaaS) and their security implications.
  • Learn to monitor cloud environments (AWS, Azure, GCP) for suspicious activity.
  • Familiarize yourself with cloud security posture management (CSPM) and cloud workload protection platforms (CWPP).
  • Understand cloud logging and auditing services (e.g., CloudTrail, Azure Monitor).
  • Practice incident response scenarios in cloud environments.
  • Learn about identity and access management (IAM) in the cloud.
  • Explore serverless security and container security best practices.
  • Understand data exfiltration techniques in cloud environments.
AWS Security Azure Security CloudTrail CSPM

Task: Cloud Alert Triage

Analyze a set of simulated cloud security alerts (e.g., unusual IAM activity, S3 bucket policy change) and determine the severity, potential impact, and initial response steps.

Week 7: Scripting for Automation & Analysis

  • Learn basic Python for security automation (e.g., parsing logs, interacting with APIs).
  • Understand PowerShell for Windows forensics and automation.
  • Explore basic Bash scripting for Linux system analysis.
  • Automate repetitive SOC tasks (e.g., IOC lookup, alert enrichment).
  • Develop simple scripts for data extraction and manipulation.
  • Understand the concept of Security Orchestration, Automation, and Response (SOAR).
  • Practice writing scripts to pull data from external APIs (e.g., VirusTotal).
  • Learn about error handling and modularity in scripting.
Python PowerShell Bash SOAR

Task: Alert Enrichment Script

Write a Python script that takes an IP address or hash as input, queries a public threat intelligence API (e.g., VirusTotal), and returns relevant information to enrich a security alert.

Week 8: Advanced Digital Forensics & Incident Response (DFIR)

  • Deepen understanding of the IR lifecycle (Preparation, Identification, Containment, Eradication, Recovery, Lessons Learned).
  • Learn about memory forensics and its importance in IR (e.g., Volatility Framework).
  • Understand disk forensics fundamentals (file systems, artifact collection).
  • Practice timeline analysis and event correlation across multiple data sources.
  • Familiarize yourself with legal and compliance considerations in IR.
  • Explore advanced containment strategies (e.g., network isolation, process termination).
  • Learn about effective communication during an incident.
  • Participate in simulated incident response exercises.
Volatility Framework FTK Imager Autopsy IR Playbooks

Task: Memory Dump Analysis

Given a memory dump from a compromised system, use Volatility to identify running processes, network connections, and any potential malware artifacts, and reconstruct a timeline of events.

🚀 Milestone 2 Achievement

You can now perform advanced threat hunting, respond to cloud security incidents, automate routine tasks with scripting, and contribute effectively to digital forensics investigations. You're ready to tackle more complex security challenges.

Projects After Phase 2

Reinforce your advanced skills with hands-on incident response and automation.

Project E: Automated Response Playbook

Design a basic automated response playbook for a common alert (e.g., suspicious login from a new geolocation). Outline the steps, including automated actions and human interventions.

Hints: Use a flow chart, consider API integrations, define clear decision points.

Project F: Cloud Incident Simulation

Simulate a cloud data exfiltration incident in a sandbox AWS/Azure environment. Identify the breach, contain it, and report on the findings and remediation steps.

Hints: Use temporary credentials, simulate S3 bucket misconfigurations or EC2 instance compromise, practice log analysis.

Project G: Advanced Network Forensics Challenge

Analyze a complex multi-stage attack scenario provided as a PCAP, identifying initial access, persistence, lateral movement, and data exfiltration. Create a detailed incident report.

Hints: Look for uncommon protocols, encoded data, C2 traffic, and analyze flow data.

Project H: Custom Threat Hunting Rule Development

Develop a new threat hunting rule (e.g., a Sigma rule or custom SIEM query) to detect a specific, sophisticated TTP not covered by existing alerts. Validate its effectiveness.

Hints: Focus on advanced adversary behaviors, test against known attack simulations or publicly available datasets.

Phase 3: Strategic Impact & Specialization

Days 61-90: Becoming a Proactive & Impactful SOC Analyst

🎯 Phase 3 Goals

Proactive Security Hardening Mentorship & Knowledge Sharing Purple Teaming Concepts Advanced Malware Analysis (Dynamic) Compliance & Reporting

Week 9: Proactive Security & Purple Teaming

  • Understand the concepts of red teaming, blue teaming, and purple teaming.
  • Learn to interpret penetration test reports and translate findings into actionable security improvements.
  • Contribute to the development of defensive strategies based on observed threats.
  • Participate in purple team exercises, working with red teams to improve detection capabilities.
  • Understand vulnerability management lifecycle and patching strategies.
  • Learn about security architecture review and secure design principles.
  • Explore deception technologies and their role in a SOC.
  • Advise on security control improvements based on incident analysis.
Red Teaming Blue Teaming Purple Teaming Vulnerability Management

Task: Purple Team Exercise Debrief

Analyze the results of a simulated purple team exercise. Identify gaps in detection and response, and propose concrete recommendations for improving security controls and SOC procedures.

Week 10: Advanced Malware Analysis (Dynamic) & Reverse Engineering

  • Set up a safe malware analysis environment (e.g., REMnux, Cuckoo Sandbox).
  • Perform basic dynamic malware analysis to observe behavior (network connections, file system changes).
  • Understand anti-analysis techniques used by malware.
  • Learn to identify common malware families based on behavior.
  • Introduction to reverse engineering tools (e.g., Ghidra, IDA Pro) for basic analysis.
  • Extract configuration and C2 information from malware samples.
  • Learn about sandboxing and its limitations.
  • Develop signatures for newly discovered malware.
REMnux Cuckoo Sandbox Ghidra IDA Pro (Free)

Task: Dynamic Malware Analysis Report

Using a provided benign executable (mimicking malware), perform dynamic analysis in a sandbox environment. Document observed behaviors, network connections, and any dropped files, and generate an IOC report.

Week 11: Security Metrics, Reporting & Compliance

  • Understand key security metrics for a SOC (MTTD, MTTR, false positive rate).
  • Learn to create impactful security reports for various stakeholders (technical, management).
  • Familiarize yourself with common compliance frameworks (e.g., NIST, ISO 27001, GDPR).
  • Understand how SOC operations contribute to compliance requirements.
  • Develop presentations on security incidents and trends.
  • Learn about auditing and evidence collection for compliance.
  • Explore risk management frameworks and their application in a SOC.
  • Communicate effectively with legal and compliance teams.
NIST CSF ISO 27001 Reporting Tools GRC

Task: Monthly SOC Report Draft

Draft a hypothetical monthly SOC report for management, including key metrics, a summary of significant incidents, and recommendations for improvement based on trends and analysis.

Week 12: Capstone & Specialization

  • Review and solidify all learned concepts through comprehensive exercises.
  • Choose an area of specialization (e.g., Cloud Security, Threat Hunting, Malware Analysis, DFIR) and deep dive further.
  • Participate in a full-scale simulated incident response exercise as a Tier 2 analyst.
  • Mentor a junior analyst (even if simulated) on a topic you've mastered.
  • Prepare for relevant certifications (e.g., GCIH, CySA+, CASP+).
  • Contribute to open-source security projects or share knowledge in forums.
  • Network with other cybersecurity professionals.
  • Reflect on your journey and identify areas for continuous improvement.
Capstone Project Specialization Certifications Networking

Task: Tier 2 SOC Analyst Simulation

Work through a comprehensive, multi-stage attack simulation that requires advanced SIEM analysis, endpoint forensics, and potentially network and cloud investigation, culminating in a detailed incident report and remediation plan.

🏆 Final Achievement

Congratulations! You've completed a rigorous 90-day roadmap, transforming into a highly capable and proactive SOC Analyst – Tier 2. You possess the skills to conduct advanced investigations, contribute to strategic security initiatives, and effectively respond to complex cyber threats.

Long-Term & Continuous Learning Projects

These projects are designed to foster continuous growth beyond the 90-day mark.

Develop a Personal Lab Environment

Build and maintain a home lab with a SIEM (e.g., Security Onion), an EDR agent, and various virtual machines (Windows, Linux) to practice detection, logging, and response scenarios.

Hints: Use virtualization software (VMware Workstation/VirtualBox), install security tools, configure logging.

Open-Source Intelligence (OSINT) Project

Choose a publicly reported cyberattack and use OSINT techniques to gather additional information about the threat actor, their infrastructure, and TTPs, beyond what is officially reported.

Hints: Use public search engines, social media, specialized OSINT tools, Shodan, Censys.

Contribute to a Threat Hunting Community

Share your threat hunting queries, Sigma rules, or analysis techniques with a relevant cybersecurity community (e.g., GitHub, security blogs, forums).

Hints: Identify a specific threat, develop a detection method, document it clearly, solicit feedback.

Pursue a Niche Specialization

Deep dive into a highly specialized area like ICS/OT security, mobile forensics, application security, or blockchain security, conducting research and building practical skills.

Hints: Identify a passionate interest, find relevant resources, pursue advanced certifications in that domain.

Project Ideas

Hands-on projects to solidify your skills at different levels of complexity.

Basic

  • Set up a basic SIEM (e.g., Wazuh or ELK) on a VM and ingest logs from a few sources (e.g., Windows Event Logs, Syslog).
  • Analyze a given Wireshark capture to identify common network protocols and basic traffic patterns.
  • Research and document 5 common cyberattack techniques (e.g., Phishing, Brute Force) and their typical indicators.
  • Configure Sysmon on a Windows VM and collect process creation events.
  • Create a simple Python script to parse a log file and extract IP addresses.

Intermediate

  • Develop a custom SIEM correlation rule to detect a specific, more complex attack chain (e.g., successful phishing leading to credential access).
  • Perform a basic network forensic investigation on a provided dataset to identify command and control (C2) communication.
  • Conduct a static and dynamic analysis of a benign executable (e.g., a simple custom script) in a controlled environment to understand its behavior.
  • Utilize a threat intelligence platform to enrich alerts and identify known malicious IOCs.
  • Write a PowerShell script to gather specific forensic artifacts from a Windows endpoint.

Advanced

  • Design and implement an automated response playbook (using a SOAR concept, even if manual steps initially) for a specific high-priority alert.
  • Lead a simulated incident response exercise, taking on the role of the lead Tier 2 analyst, coordinating with a Tier 1 analyst.
  • Perform a full memory forensic analysis on a given memory dump to identify persistence mechanisms and process injection.
  • Develop a threat hunting hypothesis based on emerging threats and execute the hunt across a simulated environment, documenting findings and new detection opportunities.
  • Create a comprehensive incident report for a multi-stage, complex attack, detailing the timeline, impact, and recommendations.

Expert

  • Contribute a new detection rule (e.g., Sigma rule) to a public repository for a novel attack technique.
  • Research and implement a deception technology (e.g., honeypot) in your lab and integrate its logs into your SIEM for anomaly detection.
  • Develop a custom tool or script to automate a complex and time-consuming SOC task.
  • Act as a mentor for aspiring SOC analysts, guiding them through complex scenarios and sharing your expertise.
  • Present a deep-dive analysis of a complex malware family or APT group's TTPs at a local meetup or online forum.

What Next

Your journey doesn't end here. Continuous learning is key in cybersecurity.

1. Specialization & Deep Dive

  • Choose an area that genuinely excites you within the SOC domain and specialize further. This could be Cloud Security, Industrial Control Systems (ICS) Security, Digital Forensics & Incident Response (DFIR), or Advanced Threat Hunting.
  • Seek out advanced certifications in your chosen specialization (e.g., SANS GIAC courses).
  • Engage with experts in that specific field through conferences, webinars, and online communities.
  • Contribute to open-source projects or write technical blogs about your deep-dive findings.

2. Proactive Security & Engineering

  • Transition towards more proactive roles like Security Engineer, building and maintaining security infrastructure.
  • Learn about security architecture, secure development lifecycles (SDLC), and DevSecOps.
  • Focus on preventing incidents rather than just reacting to them.
  • Explore offensive security concepts (ethical hacking) to better understand attacker methodologies and improve defensive strategies.

3. Leadership & Mentorship

  • Step into a leadership role within a SOC, managing teams and optimizing operations.
  • Mentor junior analysts, sharing your knowledge and experience to help them grow.
  • Develop and refine SOC playbooks, runbooks, and standard operating procedures (SOPs).
  • Contribute to strategic security planning and roadmap development for your organization.

4. Research & Innovation

  • Stay at the forefront of emerging threats and technologies by continuously researching new attack techniques and defensive measures.
  • Experiment with new security tools and platforms.
  • Participate in security conferences, give presentations, and publish research papers.
  • Explore areas like AI/ML in cybersecurity for advanced anomaly detection and automation.
