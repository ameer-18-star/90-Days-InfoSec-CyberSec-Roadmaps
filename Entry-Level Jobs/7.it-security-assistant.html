90-Day Roadmap For IT Security Assistant

A comprehensive 90-day roadmap to build foundational knowledge and practical skills for an aspiring IT Security Assistant.

Phase 1: Foundation

Days 1-30: Building Your Core Security Knowledge

🎯 Phase 1 Goals

Network Fundamentals Operating System Basics Core Security Concepts Basic Scripting Threat Landscape Awareness

Week 1: Network Fundamentals

  • Understand the OSI Model and TCP/IP Stack.
  • Learn about common networking devices (Routers, Switches, Firewalls).
  • Grasp IP Addressing, Subnetting, and basic routing.
  • Explore common network protocols (HTTP, DNS, DHCP, ARP).
  • Familiarize yourself with network topologies.
Networking TCP/IP OSI Model Routers

Task: Network Topology Mapping

Map your home network or a small hypothetical business network, identifying devices, IP ranges, and data flow.

Week 2: Operating System Basics (Windows/Linux)

  • Navigate Windows File System, understand permissions and services.
  • Learn Linux File System hierarchy (FHS), basic commands (ls, cd, pwd, mkdir, rm, cp, mv).
  • Understand Linux user and group management (chmod, chown).
  • Explore process management in both OS (Task Manager, ps, top).
  • Basic understanding of command-line interfaces (CMD, PowerShell, Bash).
Windows Linux Command Line Permissions

Task: Linux VM Setup & Navigation

Set up a basic Linux VM (e.g., Ubuntu, Kali Linux) and practice navigating its file system and executing basic commands.

Week 3: Introduction to Security Concepts

  • Deep dive into the CIA Triad (Confidentiality, Integrity, Availability).
  • Understand Risk Management principles (identification, assessment, mitigation).
  • Differentiate between vulnerabilities, threats, and exploits.
  • Learn about various security controls (technical, administrative, physical).
  • Introduction to cryptography (symmetric/asymmetric encryption, hashing).
CIA Triad Risk Management Cryptography Security Controls

Task: Risk & Control Identification

For a hypothetical small business, identify potential IT security risks and propose appropriate controls.

Week 4: Basic Scripting & Automation

  • Introduction to Bash scripting: variables, loops, conditionals.
  • Introduction to PowerShell: common cmdlets, basic scripts for system information.
  • Understand the concept of automation in IT security.
  • Learn about basic data parsing from text files using scripts.
  • Practice executing simple scripts to automate repetitive tasks.
Bash PowerShell Scripting Automation

Task: System Info Script

Write a simple Bash or PowerShell script to gather and display key system information (e.g., IP address, disk usage, running processes).

🎯 Milestone 1 Achievement

You have built a solid foundation in core IT and security fundamentals, understanding how systems and networks function and the basic principles of protecting them.

Projects After Phase 1

Apply your foundational knowledge with these hands-on projects.

Network Scanner (Basic)

Use Nmap to scan your local network to identify active hosts and open ports.

Hints: Learn Nmap commands, understand common port numbers.

File Permissions Auditor

Write a script (Bash/PowerShell) to list and analyze file permissions in a specific directory on a test system.

Hints: Focus on understanding chmod/icacls output.

Basic Incident Response Plan Draft

Draft a simple incident response plan for a common security incident, like a malware infection on a single workstation.

Hints: Follow the IR lifecycle (Preparation, Identification, Containment).

Secure OS Configuration Checklist

Create a checklist of essential security configurations for a fresh Windows or Linux operating system installation.

Hints: Think about passwords, updates, unnecessary services, firewall.

Phase 2: Intermediate Concepts

Days 31-60: Diving Deeper into Security Practices

🎯 Phase 2 Goals

Network Security System Security & Hardening Security Operations (SecOps) Incident Response Basics Compliance & Governance Concepts

Week 5: Network Security

  • Configure advanced firewall rules (stateful inspection, NAT).
  • Understand Intrusion Detection/Prevention Systems (IDS/IPS) and their role.
  • Learn about Virtual Private Networks (VPNs) and secure remote access.
  • Explore network segmentation and VLANs for security.
  • Study wireless security protocols (WPA2/3, Enterprise vs. Personal).
Firewalls IDS/IPS VPN Network Segmentation

Task: Virtual Firewall Configuration

Set up a virtual firewall (e.g., pfSense, OPNsense) in your lab and configure basic inbound/outbound rules.

Week 6: System Security & Hardening

  • Implement effective patch management strategies.
  • Understand Antivirus (AV) and Endpoint Detection and Response (EDR) solutions.
  • Master user account management and the Principle of Least Privilege.
  • Explore secure boot, disk encryption (BitLocker, LUKS), and file integrity monitoring.
  • Learn about security baselines (CIS Benchmarks, STIGs).
Patch Management EDR Least Privilege System Hardening

Task: Apply Security Baselines

Apply a basic security baseline (e.g., from CIS Benchmarks) to a test Windows or Linux system and document the changes.

Week 7: Security Operations (SecOps)

  • Introduction to Security Information and Event Management (SIEM) concepts.
  • Practice basic log analysis to identify suspicious activities.
  • Understand alert triage and incident escalation procedures.
  • Perform basic vulnerability scanning using tools like OpenVAS or Nessus (trial).
  • Learn about security monitoring tools and techniques.
SIEM Log Analysis Vulnerability Scanning SecOps

Task: Log Analysis Exercise

Analyze provided sample web server or firewall logs to identify potential attacks or anomalies.

Week 8: Incident Response & Forensics Basics

  • Understand the full Incident Response Life Cycle (Preparation, Identification, Containment, Eradication, Recovery, Post-Incident).
  • Learn basic digital forensics concepts (chain of custody, evidence collection).
  • Explore common incident types (malware, phishing, unauthorized access).
  • Familiarize yourself with incident response playbooks.
  • Practice documenting incident details accurately.
Incident Response Digital Forensics Playbooks Containment

Task: Phishing Incident Response Outline

Outline the steps you would take to respond to a simulated phishing attack targeting an employee.

🚀 Milestone 2 Achievement

You can now identify, analyze, and begin to respond to common security threats, demonstrating practical skills in network and system security, and understanding SecOps principles.

Projects After Phase 2

Solidify your intermediate skills with these practical projects.

Home Lab Security Setup

Implement network segmentation, firewall rules, and a basic SIEM (e.g., ELK stack) in a home lab environment.

Hints: Use VMs, configure logging, create dashboards.

Vulnerability Scan & Report

Conduct a vulnerability scan on a test system (e.g., Metasploitable) using OpenVAS/Nessus and generate a report with recommendations.

Hints: Prioritize vulnerabilities, suggest specific remediation steps.

Incident Response Playbook Development

Create a detailed incident response playbook for a specific incident type, such as a suspected ransomware infection.

Hints: Include roles, responsibilities, communication plan, technical steps.

Security Awareness Training Module

Develop a short presentation or module on a common security topic (e.g., "How to spot a phishing email") for non-technical users.

Hints: Keep it simple, use relatable examples, focus on actionable advice.

Phase 3: Advanced Topics & Specialization

Days 61-90: Expanding Your Horizons and Career Preparation

🎯 Phase 3 Goals

Cloud Security Fundamentals Web Application Security Advanced Threat Concepts Security Automation & Scripting Career Development & Networking

Week 9: Cloud Security Fundamentals

  • Understand Cloud Service Models (IaaS, PaaS, SaaS) and deployment models.
  • Grasp the Shared Responsibility Model in cloud security.
  • Explore security basics in major cloud providers (AWS IAM, Security Groups; Azure RBAC, NSGs; GCP IAM).
  • Learn about cloud storage security and network security in the cloud.
  • Familiarize yourself with common cloud security threats.
Cloud Security AWS Azure Shared Responsibility

Task: Cloud Security Best Practices

Identify and document security best practices for deploying a simple web application in a cloud environment (e.g., AWS EC2 with S3 storage).

Week 10: Web Application Security

  • Deep dive into the OWASP Top 10 web application security risks.
  • Understand common web vulnerabilities: SQL Injection, Cross-Site Scripting (XSS), Cross-Site Request Forgery (CSRF).
  • Learn about Web Application Firewalls (WAFs) and their role.
  • Explore secure coding principles and input validation.
  • Practice using web proxy tools like Burp Suite Community Edition or OWASP ZAP.
OWASP Web Security WAF Secure Coding

Task: Web Vulnerability Analysis

Analyze a simple, intentionally vulnerable web application (e.g., DVWA) for common vulnerabilities and attempt to exploit them in a controlled environment.

Week 11: Advanced Threat Detection & Analysis

  • Introduction to Threat Intelligence (OSINT, commercial feeds).
  • Basic malware analysis concepts (static vs. dynamic analysis, sandboxing).
  • Understand Advanced Persistent Threats (APTs) and their methodologies.
  • Explore Endpoint Detection and Response (EDR) solutions in more detail.
  • Learn about threat hunting techniques.
Threat Intelligence Malware Analysis APTs EDR

Task: APT Campaign Research

Research a recent well-known APT campaign and summarize its targets, tactics, techniques, and procedures (TTPs).

Week 12: Security Automation & Career Paths

  • Introduction to Security Orchestration, Automation, and Response (SOAR) concepts.
  • Advanced Python scripting for security tasks (e.g., using libraries like Scapy, Requests).
  • Resume building and optimizing your LinkedIn profile for security roles.
  • Practice common cybersecurity interview questions and soft skills.
  • Explore different career paths within cybersecurity (e.g., SOC Analyst, Penetration Tester, GRC Analyst).
SOAR Python Career Development Networking

Task: Python Security Script & Career Prep

Develop a Python script to automate a practical security task (e.g., network device configuration backup, log file filtering). Refine your resume and LinkedIn.

🏆 Final Achievement

Congratulations! You have completed a robust 90-day journey, gaining a comprehensive understanding of IT security, practical skills, and a clear path for further specialization. You are now well-prepared to contribute effectively as an IT Security Assistant.

Projects After Phase 3

Continue to build your portfolio and expertise with these advanced projects.

Automated Security Script

Develop a more complex Python script for a practical security task, such as automating vulnerability scan result parsing or interacting with a security API.

Hints: Consider error handling, user input, and modularity.

Cloud Security Assessment

Perform a basic security review of a cloud environment (e.g., a free-tier AWS account), focusing on IAM, network configurations, and storage security.

Hints: Use cloud-native security tools, follow best practices.

Capture The Flag (CTF) Challenge

Participate in a beginner-friendly CTF platform (e.g., TryHackMe, PicoCTF) to apply your learned skills in a gamified environment.

Hints: Focus on web, forensics, or reverse engineering challenges.

Personal Security Blog/Portfolio

Start a blog or build a personal website to document your learning journey, projects, and insights gained during this roadmap.

Hints: Share your code, write about challenges and solutions.

Project Ideas

Hands-on projects to reinforce learning and build your portfolio

Basic Projects

  • Build a simple network diagram of your home network.
  • Configure basic firewall rules on a personal computer (Windows Defender Firewall, UFW on Linux).
  • Create a strong password policy document for a small team.
  • Analyze web browser security settings and extensions.
  • Perform a basic port scan on a local machine and interpret results.

Intermediate Projects

  • Set up a honeypot (e.g., using T-Pot or Kippo) in a virtualized environment.
  • Develop a small Python script to automate log file parsing and extract key information.
  • Implement a multi-factor authentication (MFA) solution for a personal online service.
  • Conduct a basic vulnerability assessment of a test web application (e.g., DVWA).
  • Simulate a phishing attack on yourself or a willing friend (with consent!) and analyze the results.

Advanced Projects

  • Deploy a SIEM solution (e.g., ELK stack) and ingest logs from multiple sources (firewall, OS).
  • Perform basic malware analysis on a safe sample in a controlled sandbox environment.
  • Contribute to an open-source security project on GitHub.
  • Develop a custom incident response playbook for a specific, complex threat scenario.
  • Participate in a Capture The Flag (CTF) competition and solve several challenges.

What Next: Continuous Growth

  • **Continuous Learning:** The cybersecurity landscape is constantly evolving. Stay updated with new threats, technologies, and best practices.
  • **Specialization:** Explore areas like Penetration Testing, Cloud Security, Forensics, GRC, or Security Architecture based on your interests.
  • **Advanced Certifications:** Pursue higher-level certifications (e.g., OSCP, CISSP, CISM) relevant to your chosen specialization.
  • **Networking:** Connect with other security professionals, attend conferences, and participate in industry events.
  • **Hands-on Experience:** Continue building labs, participating in CTFs, and contributing to open-source projects.
  • **Mentorship:** Seek out mentors who can guide your career and consider mentoring others as you grow.
  • **Contribute to the Community:** Share your knowledge and experiences through blogs, presentations, or forums.
  • **Stay Curious:** Maintain a curious mindset and a passion for learning and problem-solving in the dynamic field of cybersecurity.
