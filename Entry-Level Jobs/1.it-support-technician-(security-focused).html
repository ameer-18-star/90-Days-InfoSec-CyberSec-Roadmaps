90-Day Roadmap For "IT Support Technician (Security-Focused)"

A comprehensive 90-day plan to become a proficient Security-Focused IT Support Technician, covering foundational IT, cybersecurity essentials, and practical application.

Phase 1: Foundational IT & Security Basics

Days 1-30: Building a strong core in IT support and initial security concepts.

🎯 Phase 1 Goals

Operating Systems Basics Networking Fundamentals Basic Troubleshooting Introduction to Cybersecurity Help Desk Procedures

Week 1: OS & Hardware Fundamentals

  • Understand core components of Windows & Linux.
  • Learn to install and configure operating systems.
  • Familiarize yourself with hardware identification and basic troubleshooting.
  • Practice basic command-line operations (CMD/PowerShell, Bash).
  • Explore user and group management.
  • Learn about file systems and permissions.
  • Understand basic BIOS/UEFI settings.
  • Introduce virtualization concepts (e.g., VirtualBox, VMware Player).
Windows 10/11 Linux (Ubuntu/CentOS) Hardware CMD/Bash

Task at the end of week: Set up a Dual-Boot System

Install Windows and a Linux distribution on a virtual machine or a spare machine, ensuring proper partitioning and boot management.

Week 2: Networking Essentials

  • Grasp TCP/IP model and OSI model basics.
  • Understand IP addressing, subnetting, and DHCP.
  • Learn about DNS resolution and common network protocols (HTTP, HTTPS, FTP, SSH).
  • Configure basic network settings on Windows and Linux.
  • Use network troubleshooting tools (ping, tracert/traceroute, ipconfig/ifconfig, netstat).
  • Differentiate between routers, switches, and hubs.
  • Understand Wi-Fi standards and basic wireless security (WPA2/3).
  • Introduce VPN concepts.
TCP/IP DNS DHCP Networking Tools

Task at the end of week: Configure a Small Home Network

Set up a small home network with a router, configure DHCP, assign static IPs, and test connectivity to various devices.

Week 3: Introduction to Cybersecurity & User Support

  • Understand the CIA Triad (Confidentiality, Integrity, Availability).
  • Learn about common cyber threats (malware, phishing, ransomware).
  • Implement basic security practices (strong passwords, MFA).
  • Familiarize yourself with antivirus and anti-malware software.
  • Develop effective communication skills for help desk interactions.
  • Learn ticket management systems and documentation best practices.
  • Understand the importance of data backup and recovery.
  • Explore basic security awareness training concepts.
CIA Triad Malware Phishing MFA

Task at the end of week: Simulate a Phishing Attack Response

Draft an email to users warning them about phishing and simulate a user reporting a suspicious email, outlining your response steps.

Week 4: Basic System & Network Security

  • Learn about firewalls (hardware and software) and basic rule configuration.
  • Understand endpoint security principles.
  • Explore patch management and software updates.
  • Learn about securing remote access (RDP, SSH best practices).
  • Introduce concepts of physical security.
  • Practice identifying and reporting security incidents.
  • Understand incident response basics for common IT issues.
  • Review and reinforce all foundational concepts.
Firewalls Endpoint Security Patch Management Remote Access

Task at the end of week: Implement Basic Firewall Rules

Configure a software firewall on a virtual machine to block specific ports and applications, then verify the rules.

🎯 Milestone 1 Achievement

You have a solid understanding of IT fundamentals, basic networking, and an introductory grasp of cybersecurity principles essential for an IT Support Technician with a security focus.

Projects After Phase 1

Apply your foundational knowledge with these practical projects.

Secure PC Setup

Perform a clean installation of Windows 10/11, including driver installation, software updates, antivirus setup, and basic firewall configuration.

Hints: Use official ISOs, create a system restore point, test internet connectivity and security software.

Network Troubleshooting Scenario

Simulate common network issues (e.g., no internet, slow connection, DNS resolution failure) in a virtualized environment and diagnose them using command-line tools.

Hints: Deliberately misconfigure network settings (IP, DNS), observe symptoms, and document troubleshooting steps.

User Account Management & Security

Create various user accounts on a Windows machine with different permissions, test their access rights, and implement strong password policies.

Hints: Local Users and Groups, Group Policy Editor (gpedit.msc).

Basic Linux Hardening

Install a basic Linux server (e.g., Ubuntu Server) in a VM and apply initial security hardening steps like SSH key authentication, disabling root login, and basic firewall rules.

Hints: OpenSSH, UFW firewall.

Phase 2: Deeper Dive into Security & Advanced Troubleshooting

Days 31-60: Expanding on cybersecurity knowledge and honing problem-solving skills.

🎯 Phase 2 Goals

Active Directory & Identity Management Threat Detection & Prevention Data Security & Privacy Scripting for Automation (Basic) Advanced Troubleshooting Methodologies

Week 5: Active Directory & Identity Management

  • Understand Active Directory (AD) concepts (domains, OUs, users, computers).
  • Learn about Group Policy Objects (GPOs) and their security implications.
  • Practice user and computer account management in AD.
  • Explore authentication protocols (Kerberos, NTLM basics).
  • Introduce single sign-on (SSO) and identity providers (IdP) concepts.
  • Learn about password policies and account lockout.
  • Understand delegated administration in AD.
  • Familiarize yourself with AD best practices for security.
Active Directory Group Policy User Management SSO

Task at the end of week: Set up a Basic AD Environment in a VM

Install and configure a Windows Server as a Domain Controller, create users and OUs, and apply a basic password policy via GPO.

Week 6: Threat Detection, Vulnerability Management & Incident Response

  • Understand common attack vectors (port scanning, brute force).
  • Learn about security information and event management (SIEM) basics.
  • Explore vulnerability scanning concepts and basic tools.
  • Familiarize yourself with common security frameworks (e.g., NIST, ISO 27001 basics).
  • Develop an understanding of incident response phases (preparation, identification, containment, eradication, recovery, post-incident).
  • Practice identifying suspicious activities from logs.
  • Learn about different types of security alerts.
  • Understand the importance of threat intelligence.
SIEM Vulnerability Scanning Incident Response Logging

Task at the end of week: Analyze Security Logs

Review Windows Event Logs and a Linux Syslog for suspicious login attempts, unauthorized access, or unusual system behavior.

Week 7: Data Security, Encryption & Cloud Security Basics

  • Understand data classification and handling.
  • Learn about different types of encryption (at rest, in transit).
  • Explore file and disk encryption solutions (BitLocker, VeraCrypt).
  • Introduce cloud computing models (IaaS, PaaS, SaaS) and basic cloud security principles.
  • Understand the shared responsibility model in cloud environments.
  • Learn about secure file sharing and collaboration.
  • Familiarize yourself with data loss prevention (DLP) concepts.
  • Explore secure data disposal methods.
Encryption BitLocker Cloud Security (Basic) DLP

Task at the end of week: Implement Disk Encryption

Encrypt a drive or partition on a virtual machine using BitLocker (Windows) or a similar tool (Linux).

Week 8: Scripting for Automation & Advanced Troubleshooting

  • Learn basic PowerShell scripting for Windows automation and security tasks.
  • Understand basic Bash scripting for Linux system management.
  • Automate repetitive tasks like user creation or log collection.
  • Develop advanced troubleshooting methodologies (e.g., top-down, bottom-up).
  • Practice diagnosing complex software and hardware issues.
  • Learn to effectively utilize diagnostic tools (Task Manager, Resource Monitor, Process Explorer).
  • Introduce basic network packet analysis (Wireshark basics).
  • Refine problem-solving skills and critical thinking.
PowerShell Bash Scripting Wireshark (Basic) Troubleshooting Tools

Task at the end of week: Automate User Creation with a Script

Write a PowerShell script to create multiple local user accounts with specific passwords and group memberships. (Adapt for Bash on Linux).

🚀 Milestone 2 Achievement

You possess intermediate knowledge of cybersecurity concepts, including Active Directory security, threat detection, data protection, and can apply basic scripting for automation and perform more advanced troubleshooting.

Projects After Phase 2

Further solidify your security-focused IT support skills with these intermediate projects.

Vulnerability Scanning & Reporting

Use a free vulnerability scanner (e.g., OpenVAS/Greenbone Community Edition, Nmap Scripting Engine) to scan a target VM and generate a report of identified vulnerabilities.

Hints: Install the scanner, configure a scan target (another VM), interpret the output.

Incident Response Simulation

Simulate a ransomware infection on a non-critical VM (e.g., using a safe sample) and practice the incident response steps: identify, contain (disconnect from network), eradicate (clean/reinstall), recover (restore from backup if available), and document.

Hints: Use a dedicated isolated VM for this, never on your main system. Document every step.

Secure Remote Access Configuration

Configure a secure remote access solution for a server (e.g., SSH with key authentication on Linux, or secure RDP gateway on Windows) and test its functionality and security settings.

Hints: Disable password authentication, use strong keys, restrict access to specific IPs.

Network Traffic Analysis

Capture network traffic using Wireshark while Browse websites or performing specific network activities. Analyze the captured packets to identify common protocols and potential security issues.

Hints: Filter traffic by protocol (HTTP, DNS), observe unencrypted login attempts if any.

OS Hardening Least Privilege Secure Disposal Security Audits

Compliance Security Policies Risk Management BCDR

Week 11: Advanced Troubleshooting & Help Desk Integration

  • Learn about remote troubleshooting tools and best practices.

  • Focus on clear and concise communication, both verbal and written.

Remote Support Knowledge Base Ticketing Systems Communication

Task at the end of week: Create a Troubleshooting Guide

Develop a detailed troubleshooting guide for a recurring IT security-related issue (e.g., malware removal, phishing report response) for help desk colleagues.

Week 12: Professional Development & Final Review

CompTIA Certifications Career Planning Networking Resume Building

Projects for Continued Growth

These projects will help you continue to expand your security-focused IT support capabilities.

Implement a SIEM Home Lab

Set up a basic SIEM solution (e.g., Splunk Free, ELK Stack) in a home lab, ingest logs from various systems, and configure basic alerts for security events.

Hints: Start with one log source, define simple correlation rules.

Automate Security Audits with PowerShell/Bash

Write scripts to automate checks for common security misconfigurations (e.g., insecure services, weak permissions, unauthorized user accounts) on Windows or Linux systems.

Hints: Use `Get-WmiObject`, `Get-Acl`, `ls -l` with filters.

Build a Secure Web Server

Set up a web server (e.g., Apache, Nginx) on a Linux VM and implement security best practices like SSL/TLS, strong ciphers, and basic intrusion prevention system (IPS) rules (e.g., ModSecurity).

Hints: Let's Encrypt, OWASP Top 10 mitigation.

Cloud Security Fundamentals Project

Deploy a simple application or virtual machine in a cloud environment (AWS Free Tier, Azure Free Account) and apply security group rules, network access control lists (NACLs), and identity and access management (IAM) best practices.

Hints: Understand public vs. private subnets, principle of least privilege for IAM users.

Project Ideas to Build Your Portfolio

Practical projects to showcase your skills and understanding.

Basic Projects

  • **Secure a Home Wi-Fi Network:** Implement WPA3, strong password, MAC filtering (if practical), guest network.
  • **Personal Data Backup & Recovery Plan:** Set up a scheduled backup solution for your critical data and practice a restore.
  • **Password Management System:** Implement and consistently use a strong password manager for all your accounts.
  • **Browser Hardening:** Configure your web browser with privacy extensions, secure DNS, and strict tracking prevention.
  • **Email Security:** Set up SPF, DKIM, and DMARC for a personal domain if you have one, or configure advanced spam filters.

Intermediate Projects

  • **Virtualization Lab Setup:** Build a small virtual network with a Windows client, a Linux client, and a server, and practice inter-OS communication and basic security settings.
  • **Active Directory Security Audit:** Perform a simulated security audit of a small Active Directory environment, identifying common misconfigurations.
  • **Endpoint Security Deployment:** Research and "deploy" a trial version of an endpoint detection and response (EDR) solution on a test VM and observe its features.
  • **Basic Log Monitoring:** Configure a central logging solution (e.g., syslog server) to collect logs from a few devices and set up simple alerts.
  • **Implement a Personal VPN Server:** Set up a VPN server on a Raspberry Pi or a cloud instance to securely access your home network or for general Browse.

Advanced Projects

  • **Build a Secure Network Segment:** Design and implement a small, segmented network using VLANs and firewall rules to isolate sensitive systems.
  • **Automated Security Patching:** Research and implement a basic automated patch management solution for a small set of test machines (e.g., using WSUS for Windows or Ansible for Linux).
  • **Develop a Security Awareness Training Module:** Create a short presentation or a set of materials to educate non-technical users on common cybersecurity threats and best practices.
  • **Contribute to an Open-Source Security Project:** Find a beginner-friendly open-source cybersecurity tool or project on GitHub and contribute documentation, bug fixes, or minor features.
  • **Simulate a Small Scale Penetration Test (Ethical):** With proper authorization, perform a basic vulnerability assessment and penetration test on a test environment using tools like Kali Linux and document your findings.

Expert Projects (Longer Term)

  • **Develop a Disaster Recovery Plan:** Create a comprehensive disaster recovery plan for a hypothetical small business, including backup strategies, recovery procedures, and communication plans.
  • **Implement a Zero Trust Network Architecture (Conceptual):** Design a conceptual zero-trust model for a small office environment, outlining how identity, device, and application trust would be established.
  • **Container Security:** Explore securing Docker containers and orchestrators like Kubernetes, including image scanning, network policies, and runtime security.
  • **Forensics & Malware Analysis Lab:** Set up an isolated lab environment to practice basic digital forensics and malware analysis techniques.
  • **Contribute to a Bug Bounty Program:** Participate in a legitimate bug bounty program (with caution and adherence to rules) to find and report security vulnerabilities.

What Next: Continued Growth

Your journey doesn't end here! Here's how to keep advancing.

1. Specialization & Advanced Certifications

  • Choose a specialization: Network Security, Cloud Security, Endpoint Security, Incident Response, etc.
  • Pursue advanced certifications: CompTIA CySA+, CASP+, Microsoft SC-Series, (ISC)² SSCP/CISSP, GIAC certifications.
  • Consider vendor-specific certifications (e.g., Cisco CCNA Security, Palo Alto PCNSA).

2. Hands-On Experience & Projects

  • Continue building complex personal projects and labs.
  • Look for volunteer opportunities in cybersecurity non-profits or community projects.
  • Contribute to open-source security tools or documentation.
  • Participate in CTF (Capture The Flag) competitions and security challenges.

3. Continuous Learning & Community Engagement

  • Stay updated with the latest cybersecurity threats, trends, and technologies by following industry news, blogs, and podcasts.
  • Attend webinars, conferences (virtual or in-person), and local meetups.
  • Join professional organizations like ISACA, ISC2, or InfraGard.
  • Mentor others or share your knowledge through blogging or presentations.

4. Career Advancement

  • Seek out roles with more security responsibility or transition into a dedicated cybersecurity analyst or engineer position.
  • Consider roles like Security Operations Center (SOC) Analyst, Junior Penetration Tester, or Security Administrator.
  • Network with professionals to find new opportunities and learn from their experiences.
  • Refine your soft skills: communication, problem-solving, critical thinking, and teamwork are crucial in cybersecurity.
