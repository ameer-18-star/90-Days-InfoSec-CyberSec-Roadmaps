90-Day Roadmap For "SOC Analyst – Tier 1"

A structured 90-day plan to develop core skills and hands-on experience for an entry-level Security Operations Center (SOC) Analyst role.

Phase 1: Foundational SOC Knowledge & Tools

Days 1-30: Building a strong base in cybersecurity, networking, and SOC operations.

🎯 Phase 1 Goals

Cybersecurity Fundamentals Networking & OS Basics SIEM Navigation Alert Triage & Escalation Incident Response Basics

Week 1: SOC Environment & Core Concepts

  • Understand the role of a SOC and its various tiers.
  • Familiarize with the organization's **SIEM (Security Information and Event Management)** platform.
  • Learn about common cybersecurity frameworks (e.g., NIST, MITRE ATT&CK - intro).
  • Understand the **CIA Triad** (Confidentiality, Integrity, Availability).
  • Get acquainted with the **ticketing system** and incident management workflow.
  • Review and understand basic **SOC playbooks** for common alerts.
  • Learn about security policies and procedures.
  • Understand communication channels within the SOC and with other teams.
SIEM (Intro) NIST/MITRE (Concepts) Ticketing System SOC Playbooks

Task at the end of week: Map the SOC workflow.

Create a simple flow chart outlining how an alert is received, triaged, and escalated within the SOC.

Week 2: Networking & Operating System Fundamentals for SOC

  • Deepen understanding of **TCP/IP model** and common network protocols (HTTP, DNS, SSH, RDP).
  • Learn about **network devices** (routers, switches, firewalls) and their logs.
  • Understand **Windows and Linux operating system fundamentals** relevant to security.
  • Familiarize with **command-line tools** for network and system information (ipconfig, netstat, ps, top).
  • Learn about common **log sources** (firewall logs, web server logs, authentication logs).
  • Understand basic **packet analysis** concepts (e.g., Wireshark intro).
  • Explore common ports and services.
  • Differentiate between public and private IP addresses.
TCP/IP Windows/Linux CLI Network Protocols Wireshark (Intro)

Task at the end of week: Analyze network logs for suspicious ports.

Given a sample log file, identify connections to unusual ports (e.g., beyond common web/email services).

Week 3: SIEM Querying & Alert Triage

  • Master basic **SIEM query language** (e.g., Splunk SPL, KQL for Sentinel/Azure Log Analytics).
  • Practice filtering, sorting, and aggregating log data.
  • Understand how **SIEM alerts** are generated and their underlying correlation rules.
  • Perform initial **alert triage**: identify false positives, benign activity, and true positives.
  • Learn to enrich alerts with contextual information (e.g., user details, asset information).
  • Document findings and update incident tickets accurately.
  • Understand the importance of baseline behavior for anomaly detection.
  • Practice escalating alerts to Tier 2 analysts with complete information.
SIEM Querying Log Enrichment Alert Triage Contextual Analysis

Task at the end of week: Investigate 10 simulated SIEM alerts.

For each alert, determine if it's a true positive, false positive, or benign, and document your reasoning.

Week 4: Endpoint Security & Malware Basics

  • Understand **Endpoint Detection and Response (EDR)** solutions and their capabilities.
  • Learn to navigate the EDR console to investigate endpoint alerts.
  • Familiarize with common **malware types** (viruses, worms, ransomware, trojans) and their indicators.
  • Understand basic **malware analysis** concepts (static vs. dynamic, sandbox environments).
  • Learn how to check **antivirus definitions** and scan status on endpoints.
  • Practice isolating infected systems from the network using EDR or network controls.
  • Understand the importance of software patching and updates.
  • Learn about common endpoint attack vectors.
EDR Solutions Malware Types Endpoint Isolation Antivirus

Task at the end of week: Simulate a malware alert investigation.

Given a simulated EDR alert, use the EDR console to gather evidence and determine initial containment steps.

🎯 Milestone 1 Achievement

You can confidently navigate the SIEM, perform initial alert triage, understand basic security incidents, and utilize core SOC tools.

Projects After Phase 1: Apply Your Foundational Skills

Choose one of the following projects to reinforce your learning:

SIEM Dashboard Creation (Basic)

Design a simple SIEM dashboard to visualize key security metrics (e.g., failed logins, top blocked IPs) from sample data.

Hints: Focus on clear, actionable data visualization for quick insights.

Incident Triage Playbook Draft

Draft a mini-playbook for a common Tier 1 alert (e.g., "Multiple Failed Logins") outlining steps for investigation and initial response.

Hints: Include data sources to check, questions to ask, and escalation criteria.

Network Traffic Analysis Scenario

Given a Wireshark capture file, identify and document suspicious network activity (e.g., unusual protocols, high volume to/from unknown IPs).

Hints: Focus on common attack patterns and anomalies.

Phase 2: Intermediate Incident Handling & Analysis

Days 31-60: Deepening incident investigation, threat intelligence, and vulnerability management.

🎯 Phase 2 Goals

Advanced SIEM Queries Incident Containment & Eradication Threat Intelligence Application Vulnerability Scanning Basics Digital Forensics (Basic)

Week 5: Advanced SIEM Querying & Rule Logic

  • Learn advanced **SIEM query techniques** (joins, subqueries, statistical functions).
  • Understand **SIEM rule logic** and how to propose minor rule enhancements.
  • Practice building custom reports and dashboards for specific security events.
  • Familiarize with different **data models** within the SIEM.
  • Understand the concept of **false positive tuning** and its importance.
  • Learn to identify missing log sources crucial for investigations.
  • Explore correlation rules and their effectiveness.
  • Participate in SIEM content review meetings.
Advanced SIEM Queries SIEM Rule Logic False Positive Tuning Custom Reports

Task at the end of week: Optimize a SIEM alert rule.

Given a high-volume, low-fidelity alert, propose and implement a minor query adjustment to reduce false positives.

Week 6: Incident Containment & Eradication

  • Deepen understanding of **incident response lifecycle**, focusing on containment and eradication.
  • Practice executing **containment actions** (e.g., disabling user accounts, blocking IPs, isolating endpoints).
  • Learn about **eradication strategies** (e.g., malware removal, patching vulnerabilities).
  • Understand the importance of **evidence preservation** during an incident.
  • Participate in **incident response calls** and document actions taken.
  • Learn about different types of containment (network, host, application).
  • Understand the concept of a "clean room" for analysis.
  • Familiarize with rollback and recovery procedures.
Incident Containment Evidence Preservation Malware Eradication Incident Documentation

Task at the end of week: Lead a simulated incident containment.

In a lab environment, contain a simulated infected host and document all steps taken for eradication.

Week 7: Threat Intelligence & Threat Hunting (Basic)

  • Understand the role of **threat intelligence platforms (TIPs)** and how to consume threat feeds.
  • Learn to identify and utilize **Indicators of Compromise (IOCs)** (IPs, domains, hashes, file names).
  • Perform basic **threat hunting** exercises using SIEM data and IOCs.
  • Familiarize with common **attack frameworks** like MITRE ATT&CK in more detail.
  • Understand the concept of **adversary tactics, techniques, and procedures (TTPs)**.
  • Learn to cross-reference internal logs with external threat intelligence.
  • Explore open-source threat intelligence sources.
  • Contribute to the internal threat intelligence repository.
Threat Intelligence IOCs MITRE ATT&CK Basic Threat Hunting

Task at the end of week: Hunt for a specific IOC in SIEM logs.

Given a known malicious IP address, search the SIEM logs to see if it has communicated with any internal assets.

Week 8: Vulnerability Management & Security Assessments

  • Understand the basics of **vulnerability management** lifecycle (identification, assessment, remediation).
  • Familiarize with **vulnerability scanning tools** (e.g., Nessus, OpenVAS - intro to reports).
  • Learn to interpret **vulnerability scan reports** and prioritize findings.
  • Understand the difference between vulnerabilities, exploits, and patches.
  • Assist in tracking and verifying remediation efforts.
  • Learn about common security misconfigurations.
  • Understand the importance of asset inventory for vulnerability management.
  • Participate in basic security assessment activities.
Vulnerability Management Vulnerability Scanners (Reports) Patching Risk Prioritization

Task at the end of week: Analyze a vulnerability scan report.

Given a sample vulnerability scan report, identify the top 3 critical vulnerabilities and suggest remediation steps.

🚀 Milestone 2 Achievement

You can perform in-depth alert analysis, contribute to incident containment, leverage threat intelligence, and understand basic vulnerability management processes.

Projects After Phase 2: Sharpen Your Investigative Skills

Choose one of the following projects to apply your intermediate knowledge:

Full Incident Report Draft

Draft a comprehensive incident report for a simulated security breach, including timeline, evidence, actions taken, and lessons learned.

Hints: Follow a standard incident report template, focus on clarity and completeness.

Threat Hunting Playbook Development (Basic)

Develop a basic threat hunting playbook for a specific MITRE ATT&CK technique (e.g., "Credential Dumping"), outlining data sources and queries.

Hints: Focus on common tools and log sources available in a typical enterprise.

Security Tool Comparison & Recommendation

Research and compare two different types of security tools (e.g., two EDRs, two vulnerability scanners) based on features, cost, and suitability for a small/medium business.

Hints: Focus on practical aspects relevant to a SOC analyst.

Phase 3: Advanced SOC Operations & Automation

Days 61-90: Focusing on automation, cloud security, compliance, and career growth.

🎯 Phase 3 Goals

Scripting for Automation Cloud Security Monitoring Compliance & Auditing Basics Security Metrics & Reporting Proactive Security Measures

Week 9: Scripting for Automation & Efficiency

  • Learn **Python or PowerShell scripting** for automating repetitive SOC tasks.
  • Write scripts to parse logs, extract IOCs, or automate data enrichment.
  • Understand the concept of **Security Orchestration, Automation, and Response (SOAR)**.
  • Explore how scripts can integrate with SIEM or EDR APIs (conceptual).
  • Identify opportunities for automation within daily Tier 1 tasks.
  • Practice basic error handling and debugging in scripts.
  • Learn about version control (Git) for managing scripts.
  • Understand the benefits of automation for SOC efficiency.
Python/PowerShell SOAR (Concepts) Log Parsing Automation

Task at the end of week: Automate an IOC lookup process.

Write a script that takes an IP address or hash as input and checks it against a public threat intelligence source (e.g., VirusTotal API - conceptual).

Week 10: Cloud Security Monitoring & SaaS Security

  • Understand basic **cloud computing concepts** (IaaS, PaaS, SaaS) and the shared responsibility model.
  • Learn about **cloud security monitoring** tools and logs (e.g., AWS CloudTrail, Azure Activity Logs).
  • Familiarize with security aspects of popular **SaaS applications** (e.g., M365 security, Google Workspace security).
  • Understand common cloud security threats and misconfigurations.
  • Learn to analyze cloud-specific security alerts in the SIEM.
  • Explore cloud identity and access management (IAM) concepts.
  • Understand container security basics (Docker, Kubernetes - intro).
  • Identify cloud-specific IOCs.
Cloud Security (Intro) SaaS Security Cloud Logs Shared Responsibility Model

Task at the end of week: Investigate a simulated cloud security alert.

Given a simulated alert (e.g., "unusual login from new region" in a cloud environment), identify relevant logs and initial actions.

Week 11: Compliance, Auditing & Reporting

  • Understand the basics of **security compliance frameworks** (e.g., GDPR, HIPAA, ISO 27001 - relevance to SOC).
  • Learn about **security auditing** principles and how SOC data contributes.
  • Familiarize with **security metrics and KPIs** used in a SOC.
  • Contribute to daily/weekly SOC reports and dashboards.
  • Understand the importance of **data retention policies** for logs and evidence.
  • Learn about internal and external audit processes.
  • Understand the role of SOC in regulatory compliance.
  • Practice summarizing complex security incidents for non-technical audiences.
Compliance (Basics) Security Metrics Reporting Data Retention

Task at the end of week: Draft a weekly SOC activity report.

Create a concise report summarizing the week's key alerts, incidents, and any significant observations for a management audience.

Week 12: Professional Development & Career Path

  • Refine **communication skills** for incident response and reporting.
  • Develop **critical thinking and problem-solving abilities** for complex security challenges.
  • Understand the career progression paths within a SOC (Tier 2, Threat Hunter, Incident Responder).
  • Prepare for common **SOC Analyst interview questions**.
  • Network with other cybersecurity professionals (online, local meetups).
  • Develop a **personal learning plan** for continuous skill enhancement.
  • Review and update your resume and LinkedIn profile.
  • Seek out mentorship opportunities.
Communication Skills Critical Thinking Career Planning Continuous Learning

Task at the end of week: Conduct a mock SOC incident briefing.

Prepare and deliver a brief (5-10 minute) presentation on a simulated security incident to a "management team".

🏆 Final Achievement

Congratulations! You have successfully completed your 90-day roadmap, gaining the essential skills and practical experience to excel as a SOC Analyst – Tier 1. You are now proficient in alert triage, incident handling, basic threat intelligence, and contributing to the organization's security posture.

Capstone Projects to Showcase Your Skills

These projects allow you to integrate all learned knowledge and demonstrate your capabilities:

Build a Mini-SOC Lab

Set up a small home lab with a SIEM (e.g., ELK Stack, Splunk Free), a few log sources (e.g., Windows/Linux VMs), and generate/analyze alerts.

Hints: Focus on log collection, basic rule creation, and dashboard visualization.

Automated IOC Checker Script

Develop a Python script that takes a list of IOCs (IPs, domains, hashes) and automatically checks them against multiple public threat intelligence sources (e.g., VirusTotal, AbuseIPDB).

Hints: Use relevant APIs, handle API keys securely, and format output clearly.

Incident Response Playbook for a Specific Threat

Create a detailed Tier 1 playbook for a specific, realistic threat (e.g., "Ransomware Initial Access via Phishing"), including detection, initial analysis, containment, and escalation steps.

Hints: Reference MITRE ATT&CK for TTPs, include communication guidelines.

Security Awareness Training Module for Employees

Develop a short, engaging security awareness training module (e.g., presentation, interactive quiz) on a topic relevant to common SOC alerts (e.g., "Identifying Suspicious Emails").

Hints: Focus on clear, concise language and actionable advice for end-users.

Project Ideas

Hands-on projects to reinforce your learning at different levels

Basic

  • **Log Collection & Analysis**: Set up a basic log collector (e.g., Syslog-ng, Nxlog) to forward logs from a VM to a local ELK Stack.
  • **Basic Alert Investigation**: Given a simple SIEM alert (e.g., "failed login from outside country"), document the investigation steps and findings.
  • **IOC Lookup Script**: Write a simple Python script to take an IP address and check it against a public blacklist (e.g., AbuseIPDB via API).
  • **MITRE ATT&CK Mapping**: For a given attack scenario, map the attacker's actions to specific MITRE ATT&CK techniques.
  • **Endpoint Process Analysis**: Use Process Explorer to analyze running processes on a Windows VM and identify any suspicious ones.

Intermediate

  • **Custom SIEM Rule Creation**: Based on a new threat, create a custom detection rule in your lab SIEM and test its effectiveness.
  • **Incident Response Tabletop Exercise**: Participate in or facilitate a small tabletop exercise for a specific security incident (e.g., ransomware attack).
  • **Threat Hunting Scenario**: Develop a threat hunting hypothesis (e.g., "Are there any lateral movement attempts?"), identify relevant data sources, and execute queries in your SIEM.
  • **Automated Remediation Script (Lab)**: Create a PowerShell script to automate a basic containment action (e.g., disable a compromised user account in a lab AD).
  • **Cloud Log Analysis**: Analyze sample AWS CloudTrail or Azure Activity Logs to identify suspicious administrative activities.

Advanced

  • **Full Incident Simulation & Report**: Design and execute a multi-stage security incident simulation in your lab, then write a comprehensive incident report.
  • **Malware Reverse Engineering (Basic)**: Perform basic static and dynamic analysis of a benign executable or script in a controlled sandbox environment.
  • **SOAR Playbook Implementation**: Implement a simple SOAR playbook using an open-source SOAR tool (e.g., Shuffle, StackStorm) to automate alert enrichment or response.
  • **Build a Custom Threat Intelligence Feed**: Aggregate IOCs from various open-source threat intelligence sources into a single, usable format.
  • **Container Security Monitoring**: Implement basic logging and monitoring for a Docker containerized application in your lab environment.

Expert (Beyond 90 Days)

  • **Develop a Custom SIEM Parser**: Write a custom parser for a new log source to integrate it into your SIEM.
  • **Contribute to Open-Source Security Tools**: Contribute code or documentation to projects like MISP, TheHive, or a security automation tool.
  • **Advanced Threat Hunting**: Develop and execute complex threat hunting queries to uncover sophisticated threats not caught by existing alerts.
  • **Security Architecture Review**: Participate in reviewing the security architecture of a new system or application from a SOC perspective.
  • **Lead a Major Incident Response**: Take a lead role in responding to a significant security incident, coordinating efforts and communicating with stakeholders.

What Next: Beyond 90 Days

Your journey as a SOC Analyst is one of continuous learning and specialization.

1. Specialization & Advanced Roles

  • **SOC Analyst – Tier 2/3**: Progress to more complex incident investigations, threat hunting, and mentoring.
  • **Incident Response (IR) Specialist**: Focus on deep dive forensics, containment, and recovery.
  • **Threat Hunter**: Proactively search for threats using advanced techniques and intelligence.
  • **Security Engineer**: Design and implement security solutions, including SIEM/EDR deployment.
  • **Security Architect**: Design secure systems and define security standards.

2. Advanced Certifications

  • **GIAC GCIH (Certified Incident Handler)**: For incident response.
  • **GIAC GCIA (Certified Intrusion Analyst)**: For network and host intrusion analysis.
  • **Offensive Security Certified Professional (OSCP)**: To understand attacker methodology.
  • **Certified Cloud Security Professional (CCSP)**: For cloud security expertise.
  • **Certified Information Systems Security Professional (CISSP)**: For management and broader security knowledge.

3. Continuous Learning & Contribution

  • **Stay Current**: Regularly follow cybersecurity news, blogs, and vulnerability disclosures.
  • **Participate in CTFs**: Engage in Capture The Flag competitions to sharpen practical skills.
  • **Research**: Conduct personal research on new attack techniques and defense strategies.
  • **Share Knowledge**: Write blog posts, present at local meetups, or contribute to open-source projects.
  • **Mentorship**: Seek out and become a mentor for junior analysts.

4. Networking & Community

  • **Industry Conferences**: Attend major cybersecurity conferences (e.g., Black Hat, RSA, DEF CON) for insights and networking.
  • **Professional Organizations**: Join ISACA, ISC2, or other relevant security groups.
  • **Online Communities**: Remain active in forums and social media discussions.
  • **Build Your Brand**: Create a professional online presence showcasing your expertise.
  • **Collaborate**: Work on security projects with peers and contribute to the community.
