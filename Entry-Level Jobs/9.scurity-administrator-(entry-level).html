90-Day Roadmap For Security Administrator (Entry-Level)

A comprehensive 90-day roadmap to build foundational knowledge and practical skills for an aspiring Entry-Level Security Administrator.

Phase 1: Core Systems & Networking Security

Days 1-30: Establishing Foundational Security Practices

🎯 Phase 1 Goals

Operating System Security Network Fundamentals for Security Identity & Access Management (IAM) Basic Security Controls Vulnerability Basics

Week 1: Operating System Security (Windows & Linux)

  • Deep dive into Windows security features (Group Policy, Local Security Policy).
  • Understand Active Directory basics: users, groups, OUs, GPOs.
  • Explore Linux user/group management, file permissions (chmod, chown), and SUID/SGID.
  • Learn about system logging and event viewers in both OS.
  • Familiarize with basic OS hardening techniques.
Windows Security Active Directory Linux Security OS Hardening

Task: Secure OS Baseline Configuration

Apply a basic security baseline (e.g., password policies, account lockout) to a test Windows Server or Linux VM.

Week 2: Network Security Fundamentals

  • Reinforce TCP/IP, common ports, and network services.
  • Understand firewall concepts: packet filtering, stateful inspection, NAT.
  • Learn about VPNs (IPsec, SSL/TLS VPNs) and their use cases.
  • Explore network segmentation strategies (VLANs, subnets).
  • Introduction to IDS/IPS systems and their deployment.
Firewall Management VPNs Network Segmentation IDS/IPS

Task: Firewall Rule Creation

Design and implement a set of firewall rules for a small office network, allowing specific traffic while blocking others.

Week 3: Identity & Access Management (IAM)

  • Understand the Principle of Least Privilege and its importance.
  • Learn about user lifecycle management (provisioning, de-provisioning).
  • Explore Multi-Factor Authentication (MFA) technologies and implementation.
  • Grasp concepts of Single Sign-On (SSO) and federated identity.
  • Familiarize with password policies, password vaults, and secrets management.
IAM Least Privilege MFA SSO

Task: User Access Review Simulation

Given a list of hypothetical users and their roles, perform an access review to identify unnecessary permissions.

Week 4: Basic Security Operations & Vulnerability Management

  • Introduction to Security Information and Event Management (SIEM) systems and log collection.
  • Learn about patch management processes and tools.
  • Understand basic vulnerability scanning concepts and tools (e.g., Nessus, OpenVAS).
  • Differentiate between security alerts, incidents, and events.
  • Practice basic security monitoring and alert triage.
SIEM Patch Management Vulnerability Scanning Security Monitoring

Task: Vulnerability Scan & Prioritization

Run a vulnerability scan on a test system and prioritize the findings based on severity and potential impact.

🎯 Milestone 1 Achievement

You have gained foundational knowledge in securing operating systems, networks, and managing identities, along with an understanding of basic security operations and vulnerability management.

Projects After Phase 1

Apply your foundational knowledge with these hands-on projects.

Active Directory Security Audit

Perform a basic security audit of a simulated Active Directory environment, checking for common misconfigurations.

Hints: Focus on password policies, stale accounts, and administrative group memberships.

Network Access Control (NAC) Design

Outline a simple NAC policy for a corporate network, detailing how different device types (e.g., corporate laptop, guest mobile) would be handled.

Hints: Consider authentication, authorization, and network segmentation.

MFA Implementation Guide

Create a step-by-step guide for implementing MFA on a common enterprise application or service (e.g., Microsoft 365, Google Workspace).

Hints: Include prerequisites, configuration steps, and user enrollment.

Basic Security Incident Playbook

Develop a mini-playbook for a common security alert, such as "High Severity Malware Detected on Endpoint," outlining initial response steps.

Hints: Focus on identification, containment, and initial communication.

Phase 2: Advanced Security Administration & Incident Response

Days 31-60: Deepening Technical Skills and Response Capabilities

🎯 Phase 2 Goals

Endpoint Security Cloud Security Administration Advanced Network Security Incident Response Lifecycle Security Automation & Scripting

Week 5: Endpoint Security Management

  • Administer Antivirus (AV) and Endpoint Detection and Response (EDR) solutions.
  • Manage host-based firewalls and intrusion prevention.
  • Understand application whitelisting/blacklisting and software restriction policies.
  • Learn about data loss prevention (DLP) concepts and tools.
  • Implement and monitor endpoint security configurations.
EDR DLP Host Firewall Application Control

Task: EDR Alert Triage

Analyze simulated EDR alerts and determine appropriate response actions (e.g., isolate host, investigate process).

Week 6: Cloud Security Administration

  • Administer IAM in a major cloud provider (AWS IAM, Azure AD, GCP IAM).
  • Configure cloud network security (Security Groups, Network Security Groups, VPC/VNet).
  • Manage cloud storage security (S3 bucket policies, Azure Blob security).
  • Understand cloud logging and monitoring services (CloudTrail, Azure Monitor, Cloud Logging).
  • Implement basic cloud resource hardening.
Cloud IAM AWS/Azure/GCP Cloud Networking Cloud Logging

Task: Cloud Storage Security Policy

Write a cloud storage policy (e.g., S3 bucket policy) to restrict access to specific users or IP ranges.

Week 7: Advanced Network Security Administration

  • Configure and manage Web Application Firewalls (WAFs).
  • Understand Secure Web Gateways (SWG) and DNS security.
  • Administer intrusion detection/prevention systems (IDS/IPS) in detail.
  • Learn about Network Access Control (NAC) solutions.
  • Explore advanced routing and switching security.
WAF SWG NAC Advanced IDS/IPS

Task: WAF Rule Configuration

Propose and configure WAF rules to protect a simple web application from common OWASP Top 10 attacks (e.g., SQL Injection, XSS).

Week 8: Incident Response & Disaster Recovery

  • Master the full Incident Response Life Cycle (Preparation, Identification, Containment, Eradication, Recovery, Post-Incident).
  • Participate in simulated incident response exercises.
  • Understand business continuity (BC) and disaster recovery (DR) planning.
  • Learn about backup and recovery strategies for security.
  • Practice documenting incident details, timelines, and lessons learned.
Incident Response BC/DR Forensics Basics Lessons Learned

Task: Ransomware Incident Response Simulation

Walk through a simulated ransomware attack, detailing containment, eradication, and recovery steps.

🚀 Milestone 2 Achievement

You are now proficient in administering various security technologies, managing cloud security, and have a solid understanding of the incident response lifecycle and disaster recovery principles.

Projects After Phase 2

Solidify your intermediate skills with these practical projects.

Endpoint Security Policy Deployment

Deploy and monitor an endpoint security policy (e.g., Windows Defender ATP, a free EDR trial) on a set of test machines.

Hints: Focus on antivirus settings, firewall rules, and device control.

Cloud Security Audit & Remediation

Conduct a security audit of a basic cloud environment (e.g., an AWS VPC with EC2 instances) and propose remediation steps for identified issues.

Hints: Use cloud-native security tools, follow CIS benchmarks.

Security Automation Script (Intermediate)

Write a Python or PowerShell script to automate a security task, such as parsing security logs for specific events or managing user accounts based on a CSV file.

Hints: Consider error handling, logging, and modularity.

Business Continuity Plan Outline

Outline a basic Business Continuity Plan (BCP) for a critical business function, including RTO/RPO objectives and key recovery steps.

Hints: Identify critical assets, dependencies, and recovery teams.

Phase 3: Governance, Risk, Compliance & Advanced Topics

Days 61-90: Strategic Security and Career Advancement

🎯 Phase 3 Goals

Governance, Risk & Compliance (GRC) Security Auditing & Assessments Security Architecture Concepts Threat Modeling & Intelligence Career Specialization

Week 9: Governance, Risk & Compliance (GRC)

  • Understand key security frameworks (NIST CSF, ISO 27001, CIS Controls).
  • Grasp regulatory compliance requirements (GDPR, HIPAA, PCI DSS - high-level).
  • Learn about risk assessment methodologies and risk registers.
  • Explore security policies, standards, and procedures development.
  • Familiarize with security awareness training program management.
GRC NIST CSF ISO 27001 Risk Assessment

Task: Security Policy Draft

Draft a basic "Acceptable Use Policy" or "Password Policy" for a small organization, aligning with best practices.

Week 10: Security Auditing & Assessments

  • Learn about internal and external security audits.
  • Understand penetration testing methodologies (reconnaissance, scanning, exploitation, post-exploitation).
  • Explore vulnerability assessment vs. penetration testing.
  • Practice reviewing audit logs for compliance and security events.
  • Familiarize with security assessment reporting.
Security Auditing Penetration Testing Vulnerability Assessment Log Review

Task: Audit Log Review Exercise

Analyze a set of simulated audit logs (e.g., Windows Security Logs, firewall logs) to identify potential policy violations or security breaches.

Week 11: Security Architecture & Design Concepts

  • Introduction to secure system design principles.
  • Understand defense-in-depth strategies.
  • Explore network architecture security (DMZ, Zero Trust).
  • Learn about secure software development lifecycle (SSDLC) basics.
  • Grasp concepts of security by design and privacy by design.
Secure Design Defense-in-Depth Zero Trust SSDLC

Task: Secure Network Design Sketch

Sketch a secure network architecture for a small enterprise, incorporating concepts like DMZ, internal networks, and secure access.

Week 12: Career Development & Specialization

  • Identify potential career paths within security administration (e.g., SysAdmin with security focus, GRC analyst, SOC Tier 1/2).
  • Refine resume and LinkedIn profile for target roles.
  • Practice interview skills, focusing on technical and behavioral questions.
  • Network with professionals in your desired specialization.
  • Plan for continuous learning and advanced certifications (e.g., CySA+, CCSP, CEH).
Career Planning Networking Interview Prep Specialization

Task: Personal Development Plan

Create a 6-month personal development plan, outlining your next learning goals, target certifications, and networking activities.

🏆 Final Achievement

Congratulations! You have completed a comprehensive 90-day roadmap, gaining essential skills and knowledge to excel as an Entry-Level Security Administrator. You are now equipped to manage security systems, respond to incidents, and contribute to an organization's overall security posture.

Projects After Phase 3

Continue to build your portfolio and expertise with these advanced projects.

Compliance Checklist Development

Create a detailed compliance checklist for a specific standard (e.g., a subset of CIS Controls) for a given system or application.

Hints: Map controls to technical implementation steps.

Automated Security Reporting

Develop a script that pulls data from various security tools (e.g., vulnerability scanner, log management) and generates a consolidated security report.

Hints: Focus on data aggregation and clear presentation.

Threat Modeling Exercise

Perform a basic threat model for a new application or system, identifying potential threats and vulnerabilities.

Hints: Use STRIDE or PASTA frameworks.

Security Awareness Campaign Material

Design a short security awareness campaign (e.g., posters, email series) on a topic like "Ransomware Prevention" for an organization.

Hints: Use engaging visuals and simple language.

Project Ideas

Hands-on projects to reinforce learning and build your portfolio

Basic Projects

  • Configure a secure baseline for a new Windows 10/11 workstation.
  • Set up a Linux server with SSH hardened and basic firewall rules.
  • Document the lifecycle of a new user account from creation to deactivation, including security considerations.
  • Analyze your home router's security settings and apply best practices.
  • Create a simple script to automate daily security checks (e.g., check for new admin accounts).

Intermediate Projects

  • Deploy a virtual firewall (e.g., pfSense) and configure advanced network segmentation.
  • Set up a basic SIEM (e.g., ELK stack) in a home lab to collect logs from a few systems.
  • Implement MFA for a personal online account and document the process.
  • Perform a vulnerability scan on a test network and create a remediation plan.
  • Develop a small security awareness training module for common threats (e.g., ransomware).

Advanced Projects

  • Configure and manage security policies within a free-tier cloud account (AWS, Azure, GCP).
  • Simulate a security incident (e.g., a phishing attack leading to credential compromise) and execute your incident response plan.
  • Automate a patch management process for a small set of test servers using scripting.
  • Research and present on a specific cybersecurity framework (e.g., NIST CSF) and how it applies to a small business.
  • Participate in a CTF challenge focused on system administration or network security.

What Next: Continuous Growth

  • **Continuous Learning:** The cybersecurity landscape is dynamic. Stay updated with emerging threats, technologies, and best practices.
  • **Specialization:** Consider specializing in areas like Cloud Security, GRC, Incident Response, or Network Security Engineering.
  • **Advanced Certifications:** Pursue higher-level certifications such as CompTIA CySA+, CCSP, or vendor-specific cloud security certs.
  • **Networking:** Actively engage with the cybersecurity community through conferences, online forums, and local meetups.
  • **Hands-on Experience:** Continue building out your home lab, experimenting with new tools, and taking on complex projects.
  • **Mentorship:** Seek out experienced professionals for guidance and consider mentoring newcomers as you progress.
  • **Contribute:** Share your knowledge and experiences by writing blog posts, giving presentations, or contributing to open-source projects.
  • **Stay Curious:** Maintain a proactive and curious mindset, always seeking to understand "how" and "why" security works (or fails).
