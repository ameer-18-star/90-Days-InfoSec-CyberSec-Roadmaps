90-Day Roadmap For Cybersecurity Technician

Your accelerated path to becoming a proficient Cybersecurity Technician, ready to defend digital assets and respond to threats.

Phase 1: Foundational Knowledge & Networking Basics

Days 1-30: Building Your Core Cybersecurity & IT Understanding

🎯 Phase 1 Goals

OS Fundamentals Networking Basics Security Principles Linux Command Line Virtualization

Week 1: Operating Systems & Basic IT

  • Understand Windows & Linux OS basics (file systems, processes, users).
  • Learn command-line interfaces (CMD/PowerShell for Windows, Bash for Linux).
  • Familiarize with basic hardware components and their functions.
  • Explore troubleshooting methodologies (e.g., CompTIA A+ concepts).
Windows Linux CMD/Bash Hardware

Task: Set up a Virtual Lab Environment

Install VirtualBox/VMware Workstation Player and deploy Windows 10 and Ubuntu Linux VMs. Practice basic commands.

Week 2: Networking Fundamentals

  • Grasp TCP/IP model, OSI model, and common network protocols (HTTP, DNS, DHCP).
  • Learn about IP addressing (IPv4/IPv6), subnets, and routing.
  • Understand network devices: routers, switches, firewalls.
  • Basic network commands: `ping`, `ipconfig`/`ifconfig`, `tracert`/`traceroute`, `netstat`.
TCP/IP OSI Model IP Addressing Network Devices

Task: Network Topology Mapping

Map your home network using `ipconfig`/`ifconfig` and `tracert`/`traceroute`. Identify devices and IP ranges.

Week 3: Core Security Concepts

  • Introduction to Confidentiality, Integrity, Availability (CIA Triad).
  • Learn about common cyber threats: malware, phishing, DoS, social engineering.
  • Understand access control models (DAC, MAC, RBAC).
  • Explore basic cryptography concepts: hashing, encryption.
CIA Triad Malware Phishing Access Control

Task: Analyze Email Headers for Phishing Indicators

Examine suspicious email headers (from your spam folder) to identify common phishing characteristics.

Week 4: Security Technologies & Practices

  • Introduction to firewalls, antivirus software, and intrusion detection/prevention systems (IDS/IPS).
  • Learn about secure coding principles (basic understanding).
  • Understand incident response basics and security policies.
  • Practice secure password management and multi-factor authentication (MFA).
Firewalls Antivirus IDS/IPS MFA

Task: Configure a Basic Firewall Rule

On your Windows VM, configure a simple outbound firewall rule to block a specific application or port.

🎯 Milestone 1 Achievement

You have built a solid foundation in IT and cybersecurity, understanding core concepts, operating systems, and networking essentials. You can navigate basic command-line interfaces and identify common security threats.

Projects After Phase 1

Apply your foundational knowledge with these hands-on projects.

Home Network Security Audit

Identify devices, open ports, and potential vulnerabilities in your home network.

Hints: Use Nmap (on Linux VM), check router settings, review connected devices.

Secure a Basic Web Server

Install Apache/Nginx on a Linux VM and implement basic security hardening (e.g., disable directory listing, secure default pages).

Hints: Research web server hardening guides, understand file permissions.

Malware Analysis Sandbox Setup (Basic)

Set up a isolated VM for safe malware analysis (do NOT use your main system). Understand basic dynamic analysis.

Hints: Use a dedicated VM, disable network access, use Process Monitor/Explorer.

Password Policy Implementation

Develop and document a strong password policy for a small imaginary business, including MFA recommendations.

Hints: Consider length, complexity, rotation, and common attack vectors.

Phase 2: Security Operations & Vulnerability Management

Days 31-60: Deepening Your Practical Skills and Threat Awareness

🎯 Phase 2 Goals

Threat Intelligence Vulnerability Scanning Log Analysis SIEM Basics Incident Response

Week 5: Network Security & Monitoring

  • Dive deeper into network security: VPNs, IDS/IPS configuration, network segmentation.
  • Learn about common network attacks (ARP poisoning, sniffing, port scanning).
  • Introduction to Wireshark for packet analysis.
  • Understand network security best practices.
VPN Wireshark Network Attacks Segmentation

Task: Packet Analysis with Wireshark

Capture and analyze network traffic on your VM. Identify common protocols and potential anomalies.

Week 6: Endpoint Security & Hardening

  • Explore endpoint protection platforms (EPP) and endpoint detection and response (EDR).
  • Learn about host-based firewalls and intrusion prevention.
  • Understand OS hardening techniques (Windows & Linux).
  • Introduction to patch management and software updates.
EPP/EDR Host Firewall OS Hardening Patch Management

Task: Harden a Linux VM

Apply basic hardening steps to your Ubuntu VM (e.g., disable unnecessary services, configure SSH securely, review user permissions).

Week 7: Vulnerability Management & Scanning

  • Understand the vulnerability management lifecycle.
  • Learn to use vulnerability scanners (e.g., OpenVAS/Greenbone, Nessus Essentials).
  • Interpret scan results and prioritize vulnerabilities.
  • Introduction to common vulnerabilities and exposures (CVEs).
OpenVAS Nessus CVE Vulnerability Lifecycle

Task: Perform a Vulnerability Scan

Scan your VMs using OpenVAS/Greenbone and identify reported vulnerabilities. Document the top 3 critical findings.

Week 8: Log Management & SIEM Basics

  • Understand the importance of logging for security.
  • Learn about different types of logs (system, application, security).
  • Introduction to log analysis tools and techniques (e.g., grep, Splunk Free, ELK Stack basics).
  • Explore the concept of Security Information and Event Management (SIEM).
Syslog Event Viewer grep SIEM

Task: Centralized Log Collection (Basic)

Set up a basic syslog server (e.g., Rsyslog) on a Linux VM to collect logs from another VM.

🚀 Milestone 2 Achievement

You can now actively monitor network traffic, harden operating systems, perform basic vulnerability scans, and understand the fundamentals of log analysis and SIEM. You're ready to contribute to security operations.

Projects After Phase 2

Reinforce your intermediate skills with these practical security projects.

Incident Response Playbook (Mini)

Develop a basic incident response playbook for a common scenario like a phishing attack or malware infection.

Hints: Define steps from detection to recovery, roles, and communication.

Active Directory Security Audit (Lab)

Set up a small Windows Server domain controller in your lab and perform a basic security audit of AD users, groups, and policies.

Hints: Focus on least privilege, strong passwords, and group memberships.

Web Application Security Scan (Basic)

Deploy a vulnerable web application (e.g., DVWA, OWASP Juice Shop) in your lab and use a web vulnerability scanner (e.g., OWASP ZAP) to identify common flaws.

Hints: Understand common OWASP Top 10 vulnerabilities.

Network Access Control (NAC) Simulation

Research NAC concepts and outline how you would implement a basic NAC solution in a small office environment.

Hints: Consider device authentication, guest access, and policy enforcement.

Phase 3: Advanced Concepts & Career Readiness

Days 61-90: Specializing and Preparing for Your Cybersecurity Career

🎯 Phase 3 Goals

Cloud Security Basics Compliance & Governance Security Automation Soft Skills Career Preparation

Week 9: Cloud Security Fundamentals

  • Introduction to cloud computing models (IaaS, PaaS, SaaS).
  • Understand shared responsibility model in cloud security.
  • Explore basic security concepts in AWS/Azure/GCP (IAM, security groups, network ACLs).
  • Learn about cloud security best practices.
AWS/Azure/GCP Shared Responsibility IAM Cloud Networking

Task: Secure a Basic Cloud Instance

Create a free-tier EC2 instance (AWS) or equivalent, and configure its security group to allow only necessary traffic.

Week 10: Governance, Risk, and Compliance (GRC)

  • Understand basic GRC concepts and their importance in cybersecurity.
  • Introduction to common security frameworks (NIST, ISO 27001).
  • Learn about data privacy regulations (GDPR, CCPA - basic awareness).
  • Explore security awareness training principles.
NIST ISO 27001 GDPR/CCPA Security Awareness

Task: Create a Security Awareness Briefing

Develop a short presentation or document on a common cybersecurity threat (e.g., phishing) for non-technical users.

Week 11: Scripting for Automation & Tools

  • Introduction to Python scripting for cybersecurity tasks (e.g., file manipulation, network scanning scripts).
  • Learn basic PowerShell scripting for Windows administration and security.
  • Explore automation concepts (e.g., automating log analysis, simple reporting).
  • Familiarize with security tools like Metasploit (ethical use only, in a controlled lab).
Python PowerShell Automation Metasploit (Lab)

Task: Simple Python Network Scanner

Write a Python script to perform a basic port scan on a target IP address within your lab environment.

Week 12: Career Development & Specialization

  • Refine your resume and LinkedIn profile for cybersecurity roles.
  • Practice common interview questions for technician roles.
  • Explore different cybersecurity career paths (SOC Analyst, GRC Analyst, Pen Tester).
  • Network with professionals in the cybersecurity community.
Resume Building Interview Prep Networking Career Paths

Task: Mock Interview & Portfolio Review

Conduct a mock interview with a peer or mentor. Review your projects and prepare to discuss them as a portfolio.

🏆 Final Achievement

Congratulations! You have completed a comprehensive 90-day roadmap, gaining practical skills in cybersecurity operations, cloud security, GRC, and automation. You are now well-prepared to pursue entry-level Cybersecurity Technician roles and continue your learning journey.

Projects After Phase 3 (Continued Growth)

These projects will help you solidify your skills and explore areas for deeper specialization.

Build a Mini-SOC Environment

Integrate a SIEM (e.g., Splunk Free, Wazuh) with multiple VMs to collect and analyze logs from different sources.

Hints: Configure log forwarding, create basic dashboards and alerts.

Automated Vulnerability Scan & Reporting

Combine a vulnerability scanner with a Python script to automate scanning and generate a simple report.

Hints: Use scanner APIs or command-line outputs, parse data with Python.

Implement a Secure Web Application (Basic)

Develop a simple web application and apply security best practices (e.g., input validation, secure authentication, error handling).

Hints: Choose a simple framework (Flask, Node.js Express), focus on common web vulnerabilities.

Cloud Security Hardening Project

Take a more complex cloud service (e.g., S3 bucket, Lambda function) and apply advanced security configurations and monitoring.

Hints: Public access blocking, encryption, logging, least privilege IAM policies.

Project Ideas

Hands-on projects to solidify your learning and build your portfolio

Basic Projects

  • Secure Home Wi-Fi: Configure WPA3, strong password, disable WPS, update firmware.
  • Linux Hardening Checklist: Apply 10 basic security configurations to a Linux VM.
  • Password Cracking Lab: Set up a lab to ethically crack weak passwords using John the Ripper.
  • Basic Firewall Configuration: Set up rules to block specific ports or IPs on a Windows/Linux host.
  • File Integrity Monitoring: Use a tool like `aide` on Linux to monitor critical system files.

Intermediate Projects

  • Set up a SIEM Lab: Deploy Splunk Free or Wazuh to collect and analyze logs from multiple VMs.
  • Vulnerability Assessment Report: Conduct a scan on a vulnerable VM and write a professional report.
  • Incident Response Simulation: Simulate a malware infection and practice containment, eradication, and recovery steps.
  • Network Intrusion Detection System (NIDS): Deploy Snort or Suricata on a Linux VM to detect malicious traffic.
  • Active Directory Security Audit: In a lab, audit user accounts, group policies, and password policies in AD.

Advanced Projects

  • Automated Security Script: Write a Python script to automate a security task (e.g., log parsing, vulnerability data aggregation).
  • Cloud Security Hardening: Secure a small cloud environment (e.g., AWS VPC, EC2 instance, S3 bucket) with best practices.
  • Web Application Penetration Testing (Lab): Use Burp Suite and OWASP ZAP to find vulnerabilities in a vulnerable web app.
  • Threat Hunting Scenario: Develop a threat hunting hypothesis and use logs/network data to investigate it.
  • Container Security Basics: Deploy a Docker container and explore basic container security practices.

Expert Projects (for continued learning)

  • Build a CTF (Capture The Flag) Challenge: Create a simple vulnerable machine or web app for others to exploit.
  • Develop a Custom Security Tool: Create a small utility in Python or PowerShell to address a specific security need.
  • Contribute to an Open-Source Security Project: Find a project on GitHub and contribute code, documentation, or bug reports.
  • Advanced Malware Analysis: Perform static and dynamic analysis on a real-world malware sample (in a highly isolated lab).
  • Implement a Zero Trust Architecture (Conceptual): Design a basic zero-trust model for a small network.

What Next? Continuous Growth in Cybersecurity

Your journey doesn't end after 90 days. Here's how to keep advancing.

1. Specialize & Certify

  • Choose a Niche: Explore areas like Cloud Security, DFIR (Digital Forensics & Incident Response), GRC, Application Security, or Penetration Testing.
  • Advanced Certifications: Consider certifications like CompTIA CySA+, PenTest+, CASP+, OSCP, CEH, or vendor-specific cloud certifications (AWS Security Specialty, Azure Security Engineer).
  • Deep Dive into a Framework: Become an expert in NIST CSF, ISO 27001, or MITRE ATT&CK.

2. Practice & Build

  • Homelab Expansion: Continuously expand and refine your home lab with more complex scenarios.
  • CTF Challenges: Regularly participate in Capture The Flag (CTF) events on platforms like TryHackMe, Hack The Box, or local competitions.
  • Personal Projects: Continue building projects that demonstrate your skills and solve real-world problems.
  • Open-Source Contributions: Contribute to open-source security tools or projects.

3. Learn & Share

  • Stay Current: Follow cybersecurity news, blogs, and podcasts. Attend webinars and virtual conferences.
  • Read Research Papers: Dive into academic papers and industry reports on emerging threats and technologies.
  • Mentorship: Seek out mentors in the industry and consider mentoring others as you gain experience.
  • Blog/Document: Start a blog or GitHub repo to document your learning, projects, and insights. Teaching is a great way to learn.

4. Network & Contribute

  • Industry Events: Attend local and national cybersecurity conferences and meetups.
  • Professional Associations: Join organizations like ISACA, ISC², or local OWASP chapters.
  • Volunteer: Contribute to cybersecurity initiatives or non-profits.
  • Community Engagement: Actively participate in online forums, Discord servers, and LinkedIn groups.
